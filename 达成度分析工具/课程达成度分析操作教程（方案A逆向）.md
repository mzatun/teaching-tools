# 课程达成度分析操作教程

> 本文档基于嘉应学院《达成度计算模版-（闭卷3+2+4）-人文地理学65.xlsx》逆向分析编制，适用于所有课程的达成度分析通用模板。

---

## 一、核心概念

| 术语 | 含义 |
|------|------|
| 课程目标 | 课程希望学生达到的学习成果，通常设3~5个 |
| 考核方式 | 平时成绩、期中考试、期末考试、实验/作业等 |
| 支撑关系 | 每个考核方式支撑哪些课程目标，用权重表示 |
| 得分率 | 学生在某考核方式中的实际得分 ÷ 满分 × 100% |
| 达成度 | 学生对课程目标的平均掌握程度，用百分比表示 |

---

## 二、输入表格格式要求

### 2.1 学生成绩原始表

| 学号 | 姓名 | 平时成绩 | 期中成绩 | 期末客观题 | 期末主观题 | ... |
|------|------|----------|----------|------------|------------|-----|
| 2024001 | 张三 | 85 | 78 | 40 | 33 | ... |
| 2024002 | 李四 | 90 | 85 | 45 | 38 | ... |

**要求**：
- 成绩为原始分（0~满分）
- 期末分拆为客观题和主观题的，需分别列出
- 满分需注明（如期末满分100，其中客观题50、主观题50）

### 2.2 课程目标支撑权重表（核心配置表）

这是最关键的一张表，决定每个课程目标由哪些考核方式支撑，以及各自的权重。

**示例（人文地理学，闭卷3+2+4）**：

| 课程目标 | 平时成绩 | 期中成绩 | 期末客观题 | 期末主观题 | 合计 |
|---------|----------|----------|------------|------------|------|
| 目标1 | 1.000 | 0 | 0 | 0 | 1.000 |
| 目标2 | 0.070 | 0.140 | 0.168 | 0.168 | 0.546 |
| 目标3 | 0.400 | 0.600 | 0 | 0 | 1.000 |
| 目标4 | 0.100 | 0.150 | 0.150 | 0.300 | 0.700 |

> **说明**：数字为权重系数，表示该考核方式对课程目标的贡献比例。目标1仅由平时成绩支撑（权重1.0），目标2由所有考核方式共同支撑。

**另一种更直观的表示方式（百分比）**：

| 课程目标 | 平时 | 期中 | 期末客观 | 期末主观 | 目标权重 |
|---------|------|------|----------|----------|----------|
| 目标1 | 100% | 0% | 0% | 0% | 3% |
| 目标2 | 13% | 26% | 31% | 30% | 53.5% |
| 目标3 | 40% | 60% | 0% | 0% | 7.5% |
| 目标4 | 14% | 21% | 21% | 43% | 36% |

> **注**："目标权重"为该目标在课程总评中的占比，合计100%。

## 三、计算过程详解

### 第一步：计算各考核方式的得分率

对每个考核方式，计算所有学生的平均得分率：

```
得分率 = (全体学生该项平均得分 ÷ 该项满分) × 100%
```

**示例**：
- 平时成绩满分100，全班平均85分 → 得分率 = 85%
- 期末客观题满分50，全班平均40分 → 得分率 = 40÷50×100% = 80%

---

### 第二步：计算每个学生各课程目标的达成度

这是模板的核心计算步骤，在Excel的"考核点对应"工作表中完成。

#### 2.1 计算单个学生的课程目标得分率

对每个学生，按支撑权重计算各课程目标的得分率：

```
学生i的目标j得分率 = 
    (平时得分率 × 目标j平时权重) +
    (期中得分率 × 目标j期中权重) +
    (期末客观得分率 × 目标j客观权重) +
    (期末主观得分率 × 目标j主观权重)
```

**示例（学生1，目标2）**：
- 平时得分率 = 85%，权重 = 0.07
- 期中得分率 = 80%，权重 = 0.14
- 期末客观得分率 = 80%，权重 = 0.168
- 期末主观得分率 = 66%，权重 = 0.168

→ 目标2得分率 = 85×0.07 + 80×0.14 + 80×0.168 + 66×0.168 = **78.181%**

（对应Excel中M3单元格的公式：`=E3*0.07+F3*0.14+G3*0.168+J3*0.45+K3*0.168`）

#### 2.2 计算单个学生的综合达成度

将各课程目标得分率按"目标权重"加权求和：

```
综合达成度 = 
    目标1得分率 × 目标1权重 +
    目标2得分率 × 目标2权重 +
    目标3得分率 × 目标3权重 +
    目标4得分率 × 目标4权重
```

**示例（学生1）**：
- 目标1：83%（权重3%）→ 贡献 = 83 × 0.03 = 2.49
- 目标2：78.181%（权重53.5%）→ 贡献 = 78.181 × 0.535 = 41.83
- 目标3：80%（权重7.5%）→ 贡献 = 80 × 0.075 = 6.0
- 目标4：70.1%（权重36%）→ 贡献 = 70.1 × 0.36 = 25.24

→ 综合达成度 = 2.49 + 41.83 + 6.0 + 25.24 = **75.56%**

（对应Excel中P3单元格的公式：`=L3*0.03+M3*0.535+N3*0.075+O3*0.36`）

---

### 第三步：计算全班级各课程目标的平均达成度

对所有学生的综合达成度取平均值：

```
目标j平均达成度 = AVERAGE(全体学生目标j得分率)
```

**示例**：
- 目标1：全体得分率平均值 = 84.21%
- 目标2：全体得分率平均值 = 80.7%
- 目标3：全体得分率平均值 = 82.46%
- 目标4：全体得分率平均值 = 77.19%

---

### 第四步：计算最终达成度（考虑等级分布）

模板采用"等级加权法"计算最终达成度，将得分率、权重、各等级人数比例综合考虑。

#### 达成度等级划分标准

| 等级 | 得分率范围 | 系数 |
|------|------------|------|
| 优秀 | ≥ 85% | 1.0 |
| 良好 | 70%~85% | 0.85 |
| 中等 | 60%~70% | 0.7 |
| 及格 | 55%~60% | 0.55 |
| 不及格 | < 55% | 0.4 |

#### 最终达成度公式

```
最终达成度 = 
    平均得分率 × 1.0 +
    目标权重 × 0.85 +
    优秀人数比例 × 0.7 +
    良好人数比例 × 0.55 +
    中等人数比例 × 0.4
```

> **说明**：此公式为模板中使用的特定计算方法，各系数可根据学校标准调整。

**示例（目标1）**：
- 平均得分率 = 84.21%
- 目标权重 = 12.28%
- 优秀人数比例 = 1.75%
- 良好人数比例 = 0%
- 中等人数比例 = 1.75%

→ 最终达成度 = 84.21×1 + 12.28×0.85 + 1.75×0.7 + 0×0.55 + 1.75×0.4 = **96.57%**

#### 课程总达成度

```
总达成度 = AVERAGE(各目标最终达成度)
```

**示例**：总达成度 = (96.57 + 96.05 + 96.32 + 95.26) / 4 = **96.05%**

## 四、Excel模板使用步骤

### 4.1 选择对应模板

| 文件名 | 适用课程类型 | 考核占比 |
|--------|--------------|----------|
| `达成度计算模版-（闭卷3+2+4）-人文地理学65.xlsx` | 闭卷考试课 | 平时30% + 期中20% + 期末50% |
| `达成度计算模版-（开卷3+1+4）-区域规划65.xlsx` | 开卷考试课 | 平时30% + 期中10% + 期末60% |
| `达成度计算模版-（实习2+1+4）-人文地理实习65.xlsx` | 实习实践课 | 平时20% + 期中10% + 期末40% + 实践30% |

### 4.2 录入学生成绩

1. 打开模板，进入"考核点对应"工作表
2. 在E列起录入各项考核原始成绩
3. 公式已预设，J~K列（得分率）会自动计算
4. L~O列（各目标达成度）会自动计算
5. P列（综合达成度）会自动计算

### 4.3 调整支撑权重（如需修改课程目标配置）

1. 进入"课程目标达成度评价依据"工作表
2. 修改各考核方式对课程目标的支撑权重
3. 返回"考核点对应"工作表，相应调整L~O列公式中的权重系数

### 4.4 查看结果

进入"计算结果"工作表：
- C列：各目标平均得分率
- H列：各目标最终达成度
- F23单元格：课程总达成度

## 六、通用模板制作指南

如需为新课程制作达成度分析模板，按以下步骤操作：

### 6.1 确定课程目标（3~5个）

明确表述每个课程目标，如：
- 目标1：掌握人文地理学的基本概念和理论体系
- 目标2：能够运用人文地理学理论分析实际问题
- 目标3：具备人文地理学田野调查和基本研究能力
- 目标4：了解人文地理学前沿动态和发展趋势

### 6.2 确定考核方式与支撑关系

| | 目标1 | 目标2 | 目标3 | 目标4 | 考核占比 |
|--|-------|-------|-------|-------|----------|
| 平时作业 | ✓ | | ✓ | | 30% |
| 期中考试 | | ✓ | | ✓ | 20% |
| 期末考试 | ✓ | ✓ | ✓ | ✓ | 50% |

### 6.3 设置权重系数

将每个考核方式对各目标的贡献比例量化为权重系数（合计为1或100%）：

在Excel中，可以用 `SUMPRODUCT` 函数计算加权得分率：
```excel
// 学生i的目标j得分率
=SUMPRODUCT(学生i各考核得分率, 目标j各考核权重) / SUM(目标j各考核权重)
```

### 6.4 复制公式到全体学生在Excel"考核点对应"工作表中：
1. 在第3行填入第一个学生的公式
2. 选中L3:O3，向下拖拽填充至所有学生行
3. P列（综合达成度）同理操作

## 七、常见问题

**Q：如果某项考核有缺考学生，如何处理？**
> 建议：缺考学生不计入统计分析；如缺考人数较多（>10%），需单独说明原因。

**Q：目标权重如何确定？**
> 建议：参考教学大纲中的考核占比，核心目标（基础知识）权重较高，拓展目标权重较低，合计100%。

**Q：达成度达到多少才算"达成"？**
> 嘉应学院一般标准：≥70%为达成，≥85%为优秀。（具体以学校最新文件为准）

**Q：如何提高效率？**
> 建议：① 直接使用本教程提供的通用模板；② 将常用权重配置保存为模板文件；③ 学生成绩录入后，所有计算自动完成。

## 八、附录：关键Excel公式参考

### 计算得分率
```excel
// J3：期末客观题得分率
=H3/50*100
```

```excel
// L3：目标1得分率（仅由平时成绩支撑）
=E3*1

// M3：目标2得分率（由多项考核支撑）
=E3*0.07+F3*0.14+G3*0.168+J3*0.45+K3*0.168
```

### 计算综合达成度
```excel
// P3：学生综合达成度
=L3*0.03+M3*0.535+N3*0.075+O3*0.36
```

### 计算最终达成度（等级加权法）
```excel
// H19：目标1最终达成度
=C19*1+D19*0.85+E19*0.7+F19*0.55+G19*0.4
```

### 计算总达成度
```excel
// F23：课程总达成度
=AVERAGE(H19:H22)
```

## 1. 工具简介

JYUGIS 课程达成度分析工具是一款基于浏览器的纯前端教学辅助工具，专为高校地理信息科学及相关专业教师设计，用于计算和分析课程目标达成度。

**核心功能：**

- 支持两种达成度计算方案：等级加权法（方案A，偏文科类）和权重分配法（方案B，偏理工实践类）
- 支持多班级分班分析与课程整体合并分析
- 自动生成包含图表的可视化分析报告（柱状图、雷达图、饼图等）
- 支持导出 HTML 报告和 Markdown 报告
- **v0.48 新增**：接入大模型（AI），上传教学大纲，一键生成专业的《课程达成度分析报告》

**工具特点：**

- 无需安装任何软件，双击 HTML 文件即可在浏览器中使用
- 数据全部在本地处理，不会上传到任何服务器（AI 报告生成功能除外）
- 支持主流浏览器：Chrome、Edge、Firefox

## 3. Excel 成绩数据准备规范

### 3.1 数据格式要求

Excel 文件需满足以下格式规范：

```
| 序号 | 学号    | 姓名 | 实操5% | 实验1 10% | 实验2 10% | 期末 50% | 总评成绩 | 备注 |
|------|---------|------|--------|-----------|-----------|----------|----------|------|
| 1    | 22110056| 张三 | 72     | 81        | 81        | 63       | 77       |      |
| 2    | 22030155| 李四 | 72     | 83        | 82        | 46       | 46       |      |
```

### 3.2 关键规则

| 规则 | 说明 |
|------|------|
| **第一行必须是表头** | 包含列名称（如"学号"、"姓名"、各考核环节名称） |
| **学号列** | 工具自动识别含"学号"、"编号"、"序号"、"号"的列 |
| **姓名列** | 工具自动识别含"姓名"、"名字"的列 |
| **成绩列** | 除学号和姓名外的其余列均为成绩列，支持百分制或实际分数 |
| **空行处理** | 工具会自动过滤空行和非学生行 |
| **支持多 Sheet** | 一个 Excel 文件可包含多个 Sheet，每个 Sheet 代表一个班级 |

### 3.3 多班级数据组织方式

**方式一：一个 Excel 文件，多个 Sheet**

```
Sheet1 "2203班" → 包含 2203 班全部学生成绩
Sheet2 "2204班" → 包含 2204 班全部学生成绩
Sheet3 "2205班" → 包含 2205 班全部学生成绩
```

**方式二：多个 Excel 文件，逐个导入**

每次导入一个文件，添加为一个班级后，再导入下一个文件。

### 3.4 常见错误及修正

| 问题 | 表现 | 解决方法 |
|------|------|---------|
| 第一行不是表头 | 数据混乱，列名显示为数字 | 在第一行添加表头行 |
| 学号列为空 | 工具无法识别学生 | 确保每行都有学号 |
| 成绩为文本格式 | 无法计算平均分 | 在 Excel 中将成绩列格式改为"数值" |
| 存在合并单元格 | 数据读取异常 | 取消所有合并单元格 |
| 表头有空列 | 工具读取多余空列 | 删除 Excel 中的空列 |

## 4. 操作流程详解

### 步骤一：选择达成度计算方案

打开工具后，首先选择计算方案。工具提供两种方案：

#### 方案A：等级加权法（偏文科类课程）

- **适用场景**：偏文科类考试课程（如人文地理学等）
- **计算逻辑**：学生得分率 → 等级分布（优秀/良好/中等/及格/不及格）→ 系数加权 → 最终达成度
- **需要配置**：支撑权重表（每目标×每环节权重系数）、等级划分标准

#### 方案B：权重分配法（偏理工实践类课程）

- **适用场景**：实践+考试课程（如 Python 编程、GIS 开发等）
- **计算逻辑**：考核环节得分 → 支撑比例 → 直接除以目标总分 → 达成度
- **需要配置**：支撑矩阵（每目标×每环节百分比）+ 环节权重

**操作**：点击选择对应方案卡片，然后点击"下一步：导入成绩"。

> **如何选择？** 如果课程以考试为主（笔试占比大），选方案A；如果课程有实验、上机操作等实践环节，选方案B。

在步骤二界面，点击虚线框区域或直接将 Excel 文件拖拽到此处。**<u>（原则上可以将教务系统中导出的成绩excel表导入）</u>**![001](F:\网易龙虾\教学相长\达成度分析\001.png)

上传成功后，工具会：

- 显示数据预览表格（前 10 行）
- 生成数据校验报告（学生人数、成绩列数、数据完整性检查）
- 自动识别学号列、姓名列和成绩列

#### 2.2 选择班级 Sheet

如果 Excel 包含多个 Sheet，点击对应的 Sheet 标签切换查看。已添加为班级的 Sheet 底部会显示绿色标记。![002](F:\网易龙虾\教学相长\达成度分析\002.png)

#### 2.3 添加班级

确认当前 Sheet 数据正确后，点击"+ 添加当前 Sheet 为班级"按钮，在弹出的对话框中输入班级名称（如"2203班"），点击确定。

重复此步骤**<u>，将所有需要分析的 Sheet 添加为班级。</u>**

![003](F:\网易龙虾\教学相长\达成度分析\003.png)

#### 2.4 列映射配置

工具会自动识别各列的含义。请检查：

- **学号列**：下拉选择正确的学号列
- **姓名列**：下拉选择正确的姓名列
- **成绩列**：*<u>勾选需要分析的成绩列（默认全选，可取消不需要的列）</u>*

> **提示**：列名中包含"学号"、"编号"、"序号"、"号"的会被识别为学号列；包含"姓名"、"名字"的会被识别为姓名列。其余列默认为成绩列，只需要选择要进行达成度分析的列。

#### 2.5 数据校验

工具会自动检查数据完整性：
- 统计有效学生人数
- 各成绩列的最低分、最高分、平均分
- 数据不完整时会显示警告提示

**确认无误后**，点击"下一步：配置权重"。

### 步骤三：配置权重参数

#### 方案B 配置（权重分配法）

##### 3.1 考核环节与权重

设置各考核环节的名称和权重百分比，**所有环节权重合计必须为 100%**。

示例：
| 环节名称 | 权重 |
|----------|------|
| 实验报告 | 30% |
| 上机操作 | 20% |
| 期末考查 | 50% |

- 点击"+ 添加考核环节"增加新环节
- 点击"删除"移除不需要的环节
- 修改权重后，工具会自动检查合计是否为 100%

##### 3.2 课程目标配置

设置课程目标的名称和数量。

示例：
- 目标1：筑牢编程根基，精研地理数据处理
- 目标2：精通空间分析与可视化，解码家乡地理信息
- 目标3：锻造项目开发实力，积累本地实战经验
- 目标4：自主学习跨界融合，紧跟前沿不辍
- 目标5：深化团队协作内涵，聚力赋能家乡发展

点击"+ 添加课程目标"增加新目标，或点击"删除"移除。

![004](F:\网易龙虾\教学相长\达成度分析\004.png)

##### 3.3 课程目标支撑矩阵

**核心配置**：填写每个课程目标在各考核环节上的支撑百分比（0~100）。

矩阵含义：行=课程目标，列=考核环节，单元格值=该考核环节对该目标的支撑比例。

示例矩阵：
| 课程目标 | 实验报告(30%) | 上机操作(20%) | 期末考查(50%) | 分目标总分 |
|----------|:---:|:---:|:---:|:---:|
| 目标1 | 10 | 20 | 30 | 22 |
| 目标2 | 40 | 30 | 40 | 38 |
| 目标3 | 30 | 20 | — | 13 |
| 目标4 | 20 | 30 | 20 | 22 |
| 目标5 | — | — | 10 | 5 |

> **"分目标总分"** 会自动计算，公式为：Σ(支撑百分比 × 环节权重 / 100)

![005](F:\网易龙虾\教学相长\达成度分析\005.png)

##### 3.4 达成度评价标准

默认标准（可不修改）：
| 达成度范围 | 评价等级 |
|-----------|---------|
| ≥ 0.9（90%） | 优秀 |
| [0.8, 0.9) | 良好 |
| [0.7, 0.8) | 中等 |
| [0.6, 0.7) | 及格 |
| < 0.6 | 不及格 |

#### 方案A 配置（等级加权法）

##### 3.1 考核方式与满分设置

设置各考核方式的名称和满分值。

##### 3.2 课程目标配置

与方案B相同，设置课程目标名称。

##### 3.3 支撑权重矩阵

矩阵值为权重系数（0~1），表示各考核方式对各目标的支撑权重。

##### 3.4 目标权重

各目标的权重百分比，**合计必须为 100%**。

##### 3.5 等级划分标准

可自定义各等级的得分率阈值和对应系数。

**配置完成后**，点击"下一步：计算达成度"。

### 步骤四：计算达成度

#### 4.1 选择分析模式

| 模式 | 说明 | 适用条件 |
|------|------|---------|
| 分班级分析 | 每个班级单独生成一份报告 | 始终可用 |
| 课程整体分析 | 合并所有班级数据计算整体达成度 | 需添加 2 个及以上班级 |
| 两者都生成 | 同时生成分班报告和整体报告 | 需添加 2 个及以上班级 |

#### 4.2 开始计算

点击"开始计算"按钮，工具会根据配置自动完成所有计算。

计算完成后自动跳转到步骤五（分析报告）。

### 步骤五：查看分析报告

#### 5.1 报告概览

报告顶部显示四个关键指标卡片：
- **课程总达成度**（带颜色等级标识）
- **分析学生人数**
- **课程目标数**
- **考核方式数**

#### 5.2 分班级切换

如果分析了多个班级或选择了"两者都生成"，报告顶部会显示班级标签，点击切换查看不同班级的报告。

#### 5.3 报告内容

报告包含以下内容：

1. **各课程目标达成度表格**：显示每个目标的达成度数值和等级
2. **达成度计算明细表**：展示各考核环节的贡献值和分目标总分
3. **各目标分项贡献明细**：每个目标在各考核环节的具体得分贡献
4. **可视化图表**：
   - 各目标达成度对比柱状图
   - 课程目标能力雷达图
   - （方案A 额外）各目标等级分布堆叠柱状图、总达成度饼图
5. **评价结论**：自动生成的文字评价
6. **学生成绩明细表**：每位学生的各目标达成度和综合达成度

#### 5.4 导出报告

| 操作 | 说明 |
|------|------|
| 打印报告 | 调用浏览器打印功能，可保存为 PDF |
| 导出为 HTML | 生成带样式的 HTML 文件，图表以图片形式嵌入 |
| 导出为 Markdown | 生成纯文本 Markdown 格式报告 |

| 重新配置 | 返回步骤三修改权重配置 |

7. **课程持续改进方案**（教学内容、教学方法、考核方式、课程发展与行业对接）
8. 签字区

## 5. 常见问题与解决方法

### Q1：打开 HTML 文件后页面空白？

**原因**：可能是浏览器安全限制或文件损坏。
**解决**：
1. 尝试换一个浏览器打开
2. 检查文件是否完整下载
3. 确保文件扩展名为 `.html`（不是 `.html.txt`）

### Q2：上传 Excel 后显示"无数据"？

**原因**：Excel 格式不符合规范。
**解决**：
1. 确保第一行是表头（列名称）
2. 确保有学号列和姓名列
3. 删除 Excel 中的空行和合并单元格
4. 将文件另存为 .xlsx 格式重试

### Q3：达成度计算结果为 0？

**原因**：支撑矩阵配置有误。
**解决**：
1. 检查支撑矩阵中是否所有值都为 0
2. 检查环节权重是否合计为 100%
3. 检查分目标总分是否为 0（不能为 0，否则无法计算）

### Q4：AI 报告生成失败？

**原因**：API 配置问题或网络问题。
**解决**：
1. 先点击"测试连接"确认 API 可用
2. 检查 API Key 是否正确
3. 如果报 CORS 错误，换用 Agnes AI 或 Ollama
4. 检查网络连接是否正常

### Q5：导出的 HTML 报告图表不显示？

**原因**：导出时图表尚未渲染完成。
**解决**：重新打开报告页面，等待图表完全加载后再导出。

### Q6：如何修改已添加的班级？

**解决**：返回步骤二，在班级管理区域点击"移除"删除当前班级，重新添加。

### Q7：如何同时分析多个班级并生成对比报告？

**操作**：
1. 在步骤二中逐个添加多个班级
2. 在步骤四中选择"两者都生成"
3. 报告中会自动显示班级切换标签

## 6. 两种计算方案对比说明

| 对比项 | 方案A：等级加权法 | 方案B：权重分配法 |
|--------|------------------|------------------|
| **适用课程** | 偏文科类考试课程 | 偏理工实践类课程 |
| **典型课程** | 人文地理学、地理信息系统原理 | Python编程、GIS开发、遥感分析 |
| **计算逻辑** | 得分率 → 等级分布 → 系数加权 | 得分 → 支撑比例 → 直接除以总分 |
| **核心配置** | 支撑权重表 + 等级标准 | 支撑矩阵 + 环节权重 |
| **结果形式** | 百分比（如 78.5%） | 小数（如 0.785） |
| **额外图表** | 等级分布堆叠图、饼图 | 无 |
| **配置复杂度** | 中等 | 中等 |

### 如何选择？

```
课程以笔试考试为主？
├── 是 → 方案A（等级加权法）
└── 否 → 课程有实验、上机操作等实践环节？
    ├── 是 → 方案B（权重分配法）
    └── 否 → 根据课程特点自行判断
```

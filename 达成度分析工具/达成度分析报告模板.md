**二、课程目标**

***课程目标\******1.\*** ***掌握遥感数据处理的基础理论与技术\***

**知识与技能：**学生应深入理解遥感图像处理的基本原理和技术，包括影像预处理（如去云、镶嵌、裁剪等）、波段合成、指数计算等。

**过程与方法：**通过理论讲授和实验操作，学生能够评估不同遥感数据源的质量和适用性，选择最适合特定任务的数据集，并独立完成复杂的预处理操作。

**情感态度价值观：**培养学生严谨的科学态度和求真务实的精神，强调遥感技术在环境保护和社会发展中的重要作用。

**课程思政：**增强学生的社会责任感，使他们认识到遥感技术对环境监测和资源管理的重要性，激发他们的使命感和责任感。

***课程目标\******2.\*** ***熟练使用\******Python\******等脚本编程进行遥感数据分析\***

**知识与技能：**学生应掌握Python语言及一些常用的相关库（如NumPy, Pandas, GDAL，Plot等）或用JavaScript，并能编写自动化脚本来实现遥感数据的检索、下载、预处理、分析及可视化展示。

**过程与方法：**通过编程练习和项目实践，学生能够高效利用在线计算平台（如AI Earth、Google Earth Engine）进行数据处理和智能计算。

**情感态度价值观：**培养学生创新精神和动手能力，鼓励他们在实践中发现问题、解决问题，提升编程能力和逻辑思维。

**课程思政：**培养学生的科技创新意识，强调编程技能在解决实际问题中的应用，激发学生的探索精神和创新能力。

***课程目标\******3.\*** ***应用机器学习等算法进行遥感影像的目标识别与分类\***

**知识与技能：**学生应熟悉常见的机器学习算法（如SVM、随机森林等），并能够应用于遥感影像的目标识别与分类任务。

**过程与方法：**通过案例研究和项目作业，学生能够在实际场景中灵活运用机器学习算法，提高其解决复杂地理信息问题的能力。

**情感态度价值观：**培养学生团队合作精神和沟通能力，鼓励他们在小组讨论和合作中分享经验、共同进步。

**课程思政：**强化学生的专业认同感，使他们认识到机器学习在地理信息科学中的重要性，激发他们的学术兴趣和职业追求。

***课程目标\******4.\*** ***解决现实世界地理信息问题的实际操作能力\***

**知识与技能：**学生应具备解决实际地理信息问题的能力，能够灵活运用所学知识和技术，完成诸如土地覆盖变化监测、森林覆盖度计算、水体提取等任务。

**过程与方法：**通过一系列由浅入深的实操练习，学生将在真实场景中独立或团队合作完成复杂的遥感数据分析任务。

**情感态度价值观：**培养学生解决实际问题的能力和自信心，鼓励他们在实践中不断总结经验，提升综合素质。

**课程思政：**增强学生的社会责任感和服务意识，使他们认识到地理信息科学在社会发展中扮演的重要角色，培养他们的奉献精神和服务意识。

***课程目标\******5.\*** ***跨界融合，了解地理智能计算的发展趋势\***

**知识与技能：**学生应了解当前遥感智能计算领域的发展方向，包括深度学习的应用、高分辨率影像处理、时空大数据分析等。

**过程与方法：**通过前沿技术探索和案例分析，学生能够跟踪新技术进展，并将其应用于改进现有的遥感数据分析方法。

**情感态度价值观：**培养学生终身学习的意识和适应发展的能力，鼓励他们关注行业动态，保持对新技术的敏感度和持续学习的动力。

**课程思政：**激发学生的爱国情怀和民族自豪感，使他们认识到我国在地理智能计算领域的成就，增强他们的文化自信和民族自豪感。

**六、达成度分析**

  **1.****分目标达成度分析**

**课程目标 1：**掌握遥感数据处理的基础理论与技术。达成度为 0.7978，达成情况良好。从考核成绩来看，学生在这方面有一定的知识掌握。教学过程中理论讲授与实验操作相结合的方式起到较好的作用，使学生能够较好地理解和运用相关知识。然而，在考核中可能存在部分学生对一些复杂原理和技术细节理解不够深入的情况，例如在涉及到某些特殊的影像预处理操作（去云操作）或指数计算的原理推导时，部分学生可能只是机械记忆，而非真正理解。

**课程目标 2：**熟练使用 Python 等脚本编程进行遥感数据分析。达成度为 0.8001，达成情况良好。通过编程练习和项目实践，学生在这方面有较好的表现。教学中注重实践操作的方式有助于提升学生的编程能力，但可能在编程思维的系统性培养上还有提升空间，导致部分学生在面对复杂逻辑的编程任务时，代码结构不够清晰，逻辑不够严谨。在考核方面，上机操作和期末考查中的编程任务能够有效检验学生的能力，但可能对于一些编程技巧的深度和广度考查还不够全面。

**课程目标 3：**应用机器学习等算法进行遥感影像的目标识别与分类。达成度为 0.8105，达成情况良好。案例研究和项目作业的教学方式帮助学生较好地掌握了相关知识和技能。不过，在教学中可能对于不同机器学习算法的适用场景和优缺点的对比分析不够深入，使得部分学生在实际应用时，不能快速准确地选择最合适的算法，或者对算法的具体使用条件不清晰。考核中对于算法应用的创新性和复杂性考查相对不足。

**课程目标 4：**解决现实世界地理信息问题的实际操作能力。达成度为 0.8026，达成情况良好。一系列的实操练习让学生具备了一定的解决实际问题的能力，但可能在真实场景的复杂性和多样性模拟上还不够充分，导致学生在面对一些特殊的实际问题时，解决思路不够灵活。考核中虽然设置了相关的实际操作任务，但在任务的综合性和难度梯度设置上还有优化的余地。

**七、课程持续改进方案**

  **（一）教学内容改进**

进一步拓展和深化各课程目标的教学内容。对于遥感数据处理基础理论与技术部分，增加一些新兴的预处理技术和复杂指数计算案例，如深度学习在影像去噪中的应用等，帮助学生更全面深入地理解和掌握该领域知识。在编程教学内容中，补充更多关于 Python 高级编程技巧和数据结构在遥感数据分析中的应用，提升学生编程能力的深度和广度。同时，加强机器学习算法的理论基础和实际应用场景的讲解，引入更多实际地理信息问题的解决案例，促进知识的融会贯通。针对地理智能计算发展趋势部分，邀请行业专家进行讲座或录制讲解视频，分享最新的研究成果和应用案例，使学生能够紧跟行业前沿动态。

**（二）教学方法改进**

采用项目驱动式教学法，设计综合性更强的项目任务，让学生在完成项目的过程中自主探索和学习知识，培养学生解决复杂实际问题的能力和团队协作精神。例如，以一个完整的区域地理信息分析项目为载体，涵盖遥感数据获取、处理、分析和结果展示等各个环节，要求学生运用所学知识和技能完成项目目标。增加互动式教学环节，如小组讨论、课堂辩论等。利用线上教学平台，提供丰富的学习资源，如在线教程、虚拟实验室等，方便学生自主学习和实践操作，满足不同学生的学习需求和进度。

**（三）考核方式改进**

过程性考核可以包括课堂表现、项目进展汇报、小组作业等方面。引入多元化的考核主体，除教师评价外，增加学生自评和互评环节。在小组项目中，小组成员相互评价各自的贡献和表现，培养学生的自我反思和评价能力，同时促进学生之间的相互学习和监督。

**（四）考核内容改进**

在期末考查中，减少记忆性知识点的考查比例，增加开放性和综合性的问题，如给定一个实际地理信息问题，要求学生设计完整的解决方案，并说明所运用的技术和方法的原理及优势，考查学生的知识综合应用能力和创新思维。上机操作考核中，设计更具挑战性的编程任务，要求学生优化代码性能、解决复杂的算法问题，并对结果进行深入分析和解释，提高对学生编程能力和问题解决能力的考查难度和深度。实验报告考核方面，加强对实验设计思路、结果分析和结论总结的要求，引导学生深入思考实验过程和结果，培养学生的科学研究思维和方法。

## 一、核心概念

### 1.1 什么是"权重分配法"

**权重分配法**是直接根据**考核环节对课程目标的支撑关系**，计算各课程目标达成度的方法。

**核心思想**：
- 每门课有多个**考核环节**（实验报告、上机操作、期末机考、期末考试等）
- 每个**考核环节**在不同**课程目标**上的支撑比例不同
- **达成度** = 各环节实际得分按支撑比例加权后 ÷ 课程目标总分

### 1.2 与"等级加权法"的区别

| 对比项 | 方法一：等级加权法 | 方法二：权重分配法 |
|--------|-------------------|-------------------|
| **适用课程** | 闭卷考试课程（人文地理学等） | 实践+考试课程（Python编程等） |
| **计算基础** | 学生得分率 → 等级分布 → 加权 | 考核环节得分 → 支撑比例 → 直接除 |
| **输出结果** | 等级达成度（优秀率×1.0+...） | 目标达成度（0~1或0%~100%） |
| **模板复杂度** | 需要支撑权重配置表 | 需要课程目标支撑矩阵 |

## 二、输入表格格式要求

### 2.1 学生成绩表（Sheet 1~n）

**用途**：记录每个学生的各项考核环节得分

**数据格式要求**：

| 列号 | 列名 | 数据类型 | 说明 | 示例 |
|--------|------|----------|------|------|
| A | 序号 | 整数 | 学生序号 | 1, 2, 3... |
| B | 学号 | 字符串 | 学生学号 | 221080096 |
| C | 姓名 | 字符串 | 学生姓名 | 曾俊轩 |
| D | 实验1 10% | 数值 | 实验报告1得分（百分制）| 85 |
| E | 实验2 10% | 数值 | 实验报告2得分（百分制）| 82 |
| F | 现场上机 5% | 数值 | 上机操作得分（百分制）| 82 |
| G | 期末机考 | 数值 | 机考原始分（百分制）| 38 |
| H | 期末机考 25% | 数值 | 机考得分×权重（公式）| `=G2*2` |
| I | 期末 | 数值 | 期末考试卷面分（百分制）| 52 |
| J | 总评 | 数值 | 总评成绩（公式）| `=D2*0.1+E2*0.1+F2*0.05+H2*0.25+I2*0.5` |

**关键公式说明**：

1. **期末机考 25%**（H列）：
   ```
   =G2*2
   ```
   - 机考原始分是50分制，乘以2转换为百分制
   - 然后乘以权重25%，即 `机考原始分×2×0.25`

2. **总评成绩**（J列）：
   ```
   =D2*0.1 + E2*0.1 + F2*0.05 + H2*0.25 + I2*0.5
   ```
   - 实验1（10%）+ 实验2（10%）+ 上机（5%）+ 机考（25%）+ 期末（50%）= 100%

**注意**：
- 如果有多个班级，每个班级单独一个Sheet（如"2203平时成绩"、"2207平时成绩"）
- 每个Sheet的最后一行应该是**平均分**（使用`AVERAGE()`函数）

### 2.2 课程目标支撑矩阵（Sheet "达成度计算"）

**用途**：定义各考核环节对不同课程目标的支撑比例

**表格结构**（前4行）：

| 行号 | A | B | C | D | E | F |
|------|---|---|---|---|---|---|
| 3 | | 实验报告20% | 上机操作5% | 期末机考25% | 期末考试50% | 分目标总分 |
| 4 | **权重** | 0.2 | 0.05 | 0.25 | 0.5 | |
| 5 | **课程目标1** | 10 | 20 | 10 | 30 | `=计算` |
| 6 | **课程目标2** | 40 | 30 | 30 | 40 | `=计算` |

**详细解读**：

1. **第4行（权重配置）**：
   - B4 = 0.2（实验报告占20%）
   - C4 = 0.05（上机操作占5%）
   - D4 = 0.25（期末机考占25%）
   - E4 = 0.5（期末考试占50%）

2. **第5~9行（支撑比例）**：
   - **课程目标1**（B5:E5）= `10, 20, 10, 30`
     - 含义：实验报告支撑10% + 上机操作支撑20% + 机考支撑10% + 期末支撑30% = **总分70分**
   - **课程目标2**（B6:E6）= `40, 30, 30, 40`
     - 含义：实验报告支撑40% + 上机操作支撑30% + 机考支撑30% + 期末支撑40% = **总分140分**
   - **课程目标3**（B7:E7）= `30, 20, 20, 0`
     - 含义：实验报告支撑30% + 上机操作支撑20% + 机考支撑20% = **总分70分**（期末不支撑）
   - **课程目标4**（B8:E8）= `20, 30, 20, 20`
     - 含义：实验报告支撑20% + 上机操作支撑30% + 机考支撑20% + 期末支撑20% = **总分90分**
   - **课程目标5**（B9:E9）= `0, 0, 20, 10`
     - 含义：机考支撑20% + 期末支撑10% = **总分30分**（实验和上机不支撑）

3. **F列（分目标总分）公式**：
   ```
   =100*B5/100*$B$4 + 100*C5/100*$C$4 + 100*D5/100*$D$4 + 100*E5/100*$E$4
   ```
   - 简化后：`= B5*$B$4 + C5*$C$4 + D5*$D$4 + E5*$E$4`
   - 计算结果：目标1总分 = 10×0.2 + 20×0.05 + 10×0.25 + 30×0.5 = **20分**

   **注意**：这里计算的是"课程目标满分值"，用于后续达成度计算的分母。

## 三、计算过程详解

### 3.1 计算步骤概览

```
步骤1：计算各考核环节班级平均分
   ↓
步骤2：计算各课程目标达成度（分班级）
   ↓
步骤3：计算课程总评平均分
   ↓
步骤4：计算课程总达成度
```

### 3.2 步骤1：计算各考核环节班级平均分

**操作位置**：每个班级Sheet的最后一行（如第46行）

**公式示例**（2203班）：
```excel
D46 = AVERAGE(D2:D45)   # 实验1平均分
E46 = AVERAGE(E2:E45)   # 实验2平均分
F46 = AVERAGE(F2:F45)   # 上机操作平均分
G46 = AVERAGE(G2:G45)   # 期末机考平均分
H46 = AVERAGE(H2:H45)   # 期末机考25%平均分
I46 = AVERAGE(I2:I45)   # 期末考试平均分
J46 = AVERAGE(J2:J45)   # 总评平均分
```

**说明**：
- 平均分用于后续课程目标达成度计算
- 如果有多个班级，每个班级单独计算

### 3.3 步骤2：计算各课程目标达成度

**操作位置**：Sheet "达成度计算" 的 B13:F17（2203班）和 I13:M17（2207班）

#### 3.3.1 核心公式解读

以**课程目标1**的**2203班**为例（B13:E13）：

```excel
B13 = $B$12 * $B5/100 * $B$4
     = 83.15  * 10/100    * 0.2
     = 83.15  * 0.1       * 0.2
     = 1.663
```

**含义**：
- `$B$12` = 2203班实验报告平均分 = 83.15
- `$B5` = 课程目标1在实验报告上的支撑比例 = 10%
- `$B$4` = 实验报告环节权重 = 20%
- **计算结果** = 实验报告对目标1的实际贡献 = 1.663分

同理：
```excel
C13 = $C$12 * $C5/100 * $C$4   # 上机操作对目标1的贡献 = 0.796
D13 = $D$12 * $D5/100 * $D$4   # 机考对目标1的贡献 = 2.085
E13 = $E$12 * $E5/100 * $E$4   # 期末对目标1的贡献 = 9.522
```

#### 3.3.2 达成度计算

**F13公式**（课程目标1达成度）：
```excel
F13 = (B13 + C13 + D13 + E13) / F5
     = (1.663 + 0.796 + 2.085 + 9.522) / 70
     = 13.066 / 70
     = 0.187
```

**含义**：
- 分子：各环节对目标1的实际贡献总和 = 13.066分
- 分母：F5 = 课程目标1总分 = 70分
- **达成度** = 13.066 / 70 = **18.7%**

**解读**：
- 达成度 < 0.6（60%）：**未达成**
- 达成度 ∈ [0.6, 0.8)（60%~80%）：**基本达成**
- 达成度 ∈ [0.8, 1.0)（80%~100%）：**较好达成**
- 达成度 ≥ 1.0（100%）：**超额达成**

#### 3.3.3 分班级计算

在模板中，2203班和2207班**分开计算**：

| 班级 | 平均分位置 | 达成度计算位置 |
|------|-------------|----------------|
| 2203班 | B12:E12 | B13:F17 |
| 2207班 | I12:L12 | I13:M17 |

**公式完全一样**，只是引用的平均分单元格不同。

### 3.4 步骤3：计算课程总评平均分

**操作位置**：Sheet "达成度计算" 的第21行

**公式示例**：
```excel
B21 = AVERAGE(B12, I12)   # 实验报告总评平均分 = (83.15 + 82.88) / 2
C21 = AVERAGE(C12, J12)   # 上机操作总评平均分
D21 = AVERAGE(D12, K12)   # 期末机考总评平均分
E21 = AVERAGE(E12, L12)   # 期末考试总评平均分
```

**说明**：
- 如果有更多班级，继续添加到`AVERAGE()`函数中
- 如果各班级权重不同（如人数不同），应使用加权平均：
  ```excel
  B21 = (B12*55 + I12*43) / (55+43)   # 按人数加权
  ```

### 3.5 步骤4：计算课程总达成度

**操作位置**：Sheet "达成度计算" 的第22~26行

**公式**：与步骤2完全相同，只是引用的是**总评平均分**（B21:E21）

```excel
B22 = $B$21 * $B5/100 * $B$4   # 实验报告对目标1的总评贡献
...
F22 = (B22 + C22 + D22 + E22) / F5   # 课程目标1总达成度
```

**最终结果**（F27单元格）：
```excel
F27 = AVERAGE(F22:F26)   # 课程总达成度 = 各目标达成度的平均值
```

## 四、Excel模板使用步骤

### 4.1 第一步：准备学生成绩表

1. **创建班级Sheet**：
   - 复制模板中的"2203平时成绩"Sheet
   - 重命名为实际班级名称（如"2201平时成绩"）
   - 清空所有学生数据（保留公式）

2. **录入学生成绩**：
   - 在D列~I列录入各项考核环节得分
   - 确保G列（期末机考）是原始分（非百分制），H列会自动计算

3. **检查总评公式**：
   - 确保J2单元格公式正确：
     ```excel
     =D2*0.1 + E2*0.1 + F2*0.05 + H2*0.25 + I2*0.5
     ```
   - 如果不一致，修改后向下填充

4. **计算班级平均分**：
   - 在最后一行（如第46行）输入公式：
     ```excel
     D46 = AVERAGE(D2:D45)
     ...
     J46 = AVERAGE(J2:J45)
     ```

### 4.2 第二步：配置课程目标支撑矩阵

1. **打开"达成度计算"Sheet**

2. **检查考核环节权重**（第4行）：
   - 确保B4:E4与实际课程一致
   - 示例：`0.2, 0.05, 0.25, 0.5`

3. **配置各课程目标支撑比例**（第5~9行）：
   - 根据实际课程目标修改B5:E9数值
   - **确保每行总分为合理值**（一般60~150分）

4. **检查分目标总分公式**（F5:F9）：
   - 确保公式正确：
     ```excel
     F5 = 100*B5/100*$B$4 + 100*C5/100*$C$4 + 100*D5/100*$D$4 + 100*E5/100*$E$4
     ```

### 4.3 第三步：录入班级平均分

1. **在B12:E12录入第一个班级的平均分**：
   - 从班级Sheet的最后一行（如D46:J46）复制数值
   - **选择性粘贴 → 数值**（不要粘贴公式）

2. **如果有第二个班级，在I12:L12录入**：
   - 同理，从第二个班级Sheet复制平均分数值

3. **检查达成度计算**（B13:F17和I13:M17）：
   - 确保公式已正确填充
   - 检查F13:F17和M13:M17的达成度数值是否合理（0~1之间）

### 4.4 第四步：计算课程总达成度

1. **检查总评平均分**（B21:E21）：
   - 确保公式正确：
     ```excel
     B21 = AVERAGE(B12, I12)
     ```

2. **检查总达成度计算**（B22:F26）：
   - 确保公式已正确填充
   - 检查F22:F26的达成度数值

3. **读取课程总达成度**（F27）：
   - 这个值就是**课程达成度**
   - 一般要求 ≥ 0.6（60%）

## 六、通用模板制作指南

### 6.1 适用于新课程的修改步骤

假设新课程有**3个课程目标**和**4个考核环节**：

#### 6.1.1 修改考核环节权重

1. 打开"达成度计算"Sheet
2. 修改第3行（环节名称）和第4行（环节权重）
3. 示例：
   ```
   第3行：平时作业10% | 实验报告20% | 期中考试30% | 期末考试40%
   第4行：0.1          | 0.2         | 0.3         | 0.4
   ```

#### 6.1.2 修改课程目标支撑比例

1. 修改第5~7行（3个目标）的B~E列数值
2. 删除第8~9行（如果不需要5个目标）
3. 示例：
   ```
   目标1：平时20% + 实验30% + 期中20% + 期末30% = 总分100
   目标2：平时10% + 实验40% + 期中30% + 期末40% = 总分120
   目标3：平时0%  + 实验30% + 期中50% + 期末20% = 总分100
   ```

#### 6.1.3 修改达成度计算公式

1. 修改F列公式（分目标总分）：
   ```excel
   F5 = B5*$B$4 + C5*$C$4 + D5*$D$4 + E5*$E$4
   ```
   **向下填充到第7行**

2. 修改B13:F15的达成度计算区域（删除第16~17行）

3. 修改总达成度公式（F18）：
   ```excel
   F18 = AVERAGE(F13:F15)
   ```

#### 6.1.4 修改学生成绩表

1. 修改D~J列的环节名称和权重
2. 修改J列（总评）公式：
   ```excel
   J2 = D2*0.1 + E2*0.2 + H2*0.3 + I2*0.4
   ```
3. 确保H列（期中考试30%）公式正确：
   ```excel
   H2 = G2 * (30/满分)   # 如果期中满分是100，则H2=G2*0.3
   ```

## 七、常见问题（FAQ）

### Q1：达成度为什么小于1？

**答**：达成度 = 实际得分 ÷ 课程目标总分。如果学生平均分较低，达成度自然会小于1。

**示例**：
- 课程目标1总分 = 70分
- 学生实际贡献 = 50分
- 达成度 = 50 / 70 = **0.714（71.4%）**

### Q2：如何判断达成度是否"合格"？

**答**：一般要求**课程总达成度 ≥ 0.6（60%）**。如果低于0.6，说明课程目标未达成，需要整改。

**整改方向**：
- 降低课程目标难度（减少支撑比例）
- 加强对应考核环节的教学
- 调整环节权重（增加学生得分高的环节权重）

### Q3：如果某个环节不支撑某课程目标怎么办？

**答**：将对应单元格设为**0**即可。

**示例**：
- 课程目标5不需要实验报告支撑
- 在B9单元格输入 `0`
- 公式会自动忽略该环节

### Q4：如何添加更多考核环节？

**答**：
1. 在"达成度计算"Sheet的第3行插入新列
2. 更新第4行（权重）和第5~9行（支撑比例）
3. 在学生成绩表中添加新环节得分列
4. 更新总评公式（J列）

### Q5：如果有超过2个班级怎么办？

**答**：
1. 在"达成度计算"Sheet中，将I~M列复制到O~S列（第三个班）、U~Y列（第四个班）...
2. 更新总评平均分公式（B21）：
   ```excel
   B21 = AVERAGE(B12, I12, O12, U12)   # 4个班的平均分
   ```
3. 如果班级人数不同，使用加权平均：
   ```excel
   B21 = (B12*50 + I12*45 + O12*48 + U12*47) / (50+45+48+47)
   ```

| 单元格 | 公式 | 说明 |
|--------|------|------|
| F5 | `=100*B5/100*$B$4 + 100*C5/100*$C$4 + 100*D5/100*$D$4 + 100*E5/100*$E$4` | 课程目标1总分 |
| B13 | `=$B$12*$B5/100*$B$4` | 实验报告对目标1的贡献 |
| F13 | `=(B13+C13+D13+E13)/F5` | 课程目标1达成度 |
| F18 | `=AVERAGE(F13:F17)` | 2203班课程总达成度 |
| B21 | `=AVERAGE(B12,I12)` | 实验报告总评平均分 |
| F27 | `=AVERAGE(F22:F26)` | 课程总达成度 |

## 九、总结

### 9.1 两种方法对比

| 对比项 | 方法一：等级加权法 | 方法二：权重分配法 |
|--------|-------------------|-------------------|
| **核心公式** | `=C*1+D*0.85+E*0.7+F*0.55+G*0.4` | `=(实际贡献1+实际贡献2+...)/总分` |
| **计算基础** | 学生得分率分布 | 考核环节实际得分 |
| **输出结果** | 0~1之间的达成度 | 0~1之间的达成度 |
| **适用场景** | 闭卷考试课程 | 实践+考试课程 |
| **模板复杂度** | 中等 | 较高 |

### 9.2 方法二的优点

1. **直观**：直接反映各考核环节对课程目标的贡献
2. **灵活**：可以任意调整支撑比例和环节权重
3. **可诊断**：通过分目标达成度，可以精准发现教学薄弱环节

### 9.3 方法二的缺点

1. **模板复杂**：需要配置支撑矩阵，不适合新手
2. **数据要求高**：需要准确的环节得分和权重配置
3. **计算步骤多**：容易在公式引用上出错

# 课程达成度分析工具

> 基于浏览器的单文件 HTML 工具，无需安装，双击即用。  
> Single-file HTML tool for course attainment analysis — no installation required.

---

## 📋 功能简介

本课程达成度分析工具用于 **基于 Excel 成绩表自动计算课程达成度**，支持两种计算方案，适用于嘉应学院 GIS/测绘遥感专业课程评价。

**核心功能：**
- 📥 Excel 成绩表导入（`.xlsx`）
- 📊 等级加权法（方案A）和权重分配法（方案B）两种计算模式
- 🏫 多班级分班与合并分析
- 📄 达成度报告预览与打印
- 🤖 **v0.48 新增**：接入大模型 API，自动生成课程达成度分析报告

### 🔧 使用方法

1. 用浏览器打开 `达成度分析工具v0.48.html`
2. 按步骤导入成绩表 → 配置课程信息 → 计算达成度
3. 计算完成后，点击 **「AI 生成达成度报告」** 按钮
4. 在弹出的配置面板中：
   - 选择大模型平台（推荐 Agnes AI，免费免 Key）
   - 填入 API Key（Agnes AI 可留空）
   - 点击 **「测试连接」** 验证配置
   - 点击 **「确认配置」** 保存
5. 填写报告学期和班级，点击 **「开始生成」**
6. 等待 AI 生成报告（约 10~30 秒）
7. 生成后可 **预览 / 打印 / 导出**

### ⚠️ 注意事项

- **API Key 安全**：Key 仅保存在浏览器本地存储（LocalStorage），不会上传至任何服务器。
- **网络要求**：AI 报告生成需要联网访问对应大模型 API 地址。
- **Agnes AI**：提供免费额度，无需配置 Key，适合快速试用。
- **报告质量**：AI 生成报告仅供参考，正式提交前请人工核对。

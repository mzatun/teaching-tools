# 青少年编程天赋免费测评H5工具 - 需求分析

## 1. 项目背景

### 1.1 产品定位
基于科宝AI青少年编程天赋测评的设计理念，为我们的青少年编程课程体系打造一款**免费、科学、有趣**的H5测评工具，帮助家长深入了解孩子的思维特质与学习风格，精准匹配适合的课程体系，提供个性化学习支持。

### 1.2 目标用户
- **核心用户**：6-15岁青少年（小学1年级至初中）
- **决策用户**：家长（30-45岁，关注孩子素质教育）
- **使用场景**：微信生态内（朋友圈分享、家长群传播、公众号引流）

### 1.3 竞品参考
参考「科宝AI编程天赋测评」的设计思路：
- 零门槛：无需编程基础
- 趣味性：游戏化答题体验
- 科学性：五维天赋评估体系
- 实用性：个性化课程推荐
- 免费模式：降低尝试门槛

## 2. 功能需求

### 2.1 核心功能模块

#### **M1：用户进入与授权**
| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 微信授权登录 | 获取用户openid，无需注册 | P0 |
| 年级选择 | 适配不同难度（1-3年级/4-6年级/初中） | P0 |
| 隐私协议 | 明确告知数据使用规则 | P0 |

#### **M2：测评答题系统**
| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 题目展示 | 25道选择题，图文结合 | P0 |
| 进度提示 | 显示当前题号/总题数 | P0 |
| 答题交互 | 点击选项自动下一题 | P0 |
| 返回修改 | 可回溯修改已答题目 | P1 |
| 倒计时提醒 | 每题不限时，但总时长建议5-8分钟 | P2 |

#### **M3：结果计算与可视化**
| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 五维评分 | 逻辑思维、创意实现、概念理解、专注毅力、协作沟通 | P0 |
| 雷达图生成 | Canvas绘制，支持分享 | P0 |
| 综合报告 | 文字解读+学习建议 | P0 |
| 课程匹配 | 根据测评结果推荐适合的课程 | P0 |

#### **M4：社交分享与转化**
| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 海报生成 | 将雷达图+二维码合成分享图 | P0 |
| 微信分享 | 支持转发给朋友/朋友圈 | P1 |
| 客服对接 | 引导添加微信领取详细报告 | P0 |
| 试听预约 | 跳转表单预约线下体验课 | P1 |

## 3. 非功能需求

### 3.1 性能要求
| 指标 | 要求 |
|------|------|
| 页面加载时间 | <2秒（4G网络） |
| 答题流畅度 | 切换题目无卡顿 |
| 并发支持 | 支持1000+同时在线 |
| 兼容性 | 微信内置浏览器（iOS/Android） |

### 3.2 安全要求
- 用户数据加密存储（AES-256）
- 不收集敏感个人信息（仅需年级+昵称）
- 遵守《个人信息保护法》和《未成年人保护法》

### 3.3 可用性要求
- 操作流程：**3步完成**（进入→答题→看结果）
- 学习成本：**零门槛**，6岁孩子可独立操作
- 容错设计：网络中断可断点续答

## 4. 数据需求

### 4.1 题目库设计
```
总量：75题（每个年级段25题）
题型：单项选择题（4选1）
维度：每题对应1-2个测评维度
难度：自适应（根据年级段调整）
```

### 4.2 评分算法
```javascript
// 五维评分逻辑（示例）
const dimensions = {
  logic: 0,        // 逻辑思维
  creativity: 0,    // 创意实现
  concept: 0,       // 概念理解
  focus: 0,         // 专注毅力
  collaboration: 0   // 协作沟通
}

// 每题根据选项加分（0-4分）
// 最终归一化为百分制（0-100）
```

### 4.3 课程匹配规则
| 优势维度 | 推荐课程 |
|----------|----------|
| 逻辑思维高 | Python编程、算法竞赛 |
| 创意实现高 | Scratch游戏设计、动画制作 |
| 概念理解高 | C++基础、数学逻辑思维 |
| 专注毅力高 | 长期项目制课程 |
| 协作沟通高 | 团队编程、开源项目体验 |

## 5. 业务流程

### 5.1 用户旅程图
```
[扫码/点击链接] 
      ↓
[授权登录 + 选择年级] 
      ↓
[开始测评 - 25题] 
      ↓
[提交答题] 
      ↓
[生成雷达图 + 报告] 
      ↓
[分享海报 / 领取详细报告]
```

### 5.2 关键业务规则
1. **防作弊机制**：同一微信账号7天内只能测一次
2. **数据留存**：测评结果保存90天，供后续查阅
3. **客服转化**：测评后引导添加客服微信（企业微信）
4. **A/B测试**：可配置不同题目版本，优化转化率

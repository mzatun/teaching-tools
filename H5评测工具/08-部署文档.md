## 2. 服务器环境配置

### 2.1 操作系统初始化（Ubuntu 20.04）

```bash
# 1. 更新系统
sudo apt update && sudo apt upgrade -y

# 2. 安装基础工具
sudo apt install -y vim curl wget git build-essential

# 3. 配置时区（Asia/Shanghai）
sudo timedatectl set-timezone Asia/Shanghai

# 4. 配置防火墙（仅开放80/443/22端口）
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# 5. 创建部署用户（非root）
sudo adduser deploy
sudo usermod -aG sudo deploy
su - deploy
```

### 2.2 安装Node.js（后端）

```bash
# 1. 安装NVM（Node Version Manager）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc

# 2. 安装Node.js 18.x LTS
nvm install 18
nvm use 18
node -v  # 应显示 v18.x.x
npm -v   # 应显示 9.x.x

# 3. 安装PM2（进程管理器）
npm install -g pm2
pm2 --version  # 应显示 5.x.x
```

### 2.3 安装MySQL（数据库）

```bash
# 方案A：使用云数据库RDS（推荐）
# - 在阿里云/腾讯云控制台创建RDS实例
# - 配置安全组（仅允许应用服务器IP访问）
# - 创建数据库：h5_quiz

# 方案B：自建MySQL（不推荐生产环境）
# 1. 安装MySQL
sudo apt install mysql-server

# 2. 安全配置
sudo mysql_secure_installation

# 3. 登录MySQL
sudo mysql -u root -p

# 4. 创建数据库和用户
CREATE DATABASE h5_quiz CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'h5quiz'@'%' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON h5_quiz.* TO 'h5quiz'@'%';
FLUSH PRIVILEGES;
EXIT;

# 5. 配置远程访问（如需要）
sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
# 修改 bind-address = 0.0.0.0

sudo systemctl restart mysql
```

### 2.4 安装Redis（缓存）

```bash
# 方案A：使用云数据库Redis（推荐）
# - 在阿里云/腾讯云控制台创建Redis实例
# - 配置密码和VPC网络

# 方案B：自建Redis（不推荐生产环境）
# 1. 安装Redis
sudo apt install redis-server

# 2. 配置Redis
sudo nano /etc/redis/redis.conf
# 修改以下配置：
# bind 127.0.0.1  # 仅本地访问（生产环境）
# requirepass your_redis_password  # 设置密码
# maxmemory 1073741824  # 1GB内存限制
# maxmemory-policy allkeys-lru  # 内存满时删除最近最少使用的key

# 3. 启动Redis
sudo systemctl restart redis
sudo systemctl enable redis
```

### 2.5 安装Nginx（反向代理）

```bash
# 1. 安装Nginx
sudo apt install nginx

# 2. 配置防火墙（已配置，见2.1）

# 3. 测试Nginx
sudo systemctl status nginx
# 浏览器访问 http://服务器IP，应看到Nginx欢迎页

# 4. 配置反向代理（见第3节）
```

## 3. 应用部署

### 3.1 前端部署（静态资源）

#### **方案A：部署到CDN（推荐）**

```bash
# 1. 在本地构建前端项目
cd h5-quiz
npm run build  # 输出到 dist/ 目录

# 2. 上传到阿里云OSS / 腾讯云COS
# 使用OSS/COS客户端工具，拖拽上传 dist/ 目录所有文件

# 3. 配置CDN加速域名
# - 在OSS/COS控制台绑定自定义域名（如 cdn.xxx.com）
# - 开启CDN加速
# - 配置HTTPS证书（免费SSL证书）
```

#### **方案B：部署到Nginx（小型项目）**

```bash
# 1. 在服务器创建部署目录
sudo mkdir -p /var/www/h5-quiz
sudo chown -R deploy:deploy /var/www/h5-quiz

# 2. 上传前端构建文件
# 在本地执行：
scp -r dist/* deploy@服务器IP:/var/www/h5-quiz/

# 3. 配置Nginx（见3.3节）
```

### 3.2 后端部署（Node.js应用）

```bash
# 1. 在服务器克隆代码
cd ~
git clone https://github.com/xxx/h5-quiz-server.git
cd h5-quiz-server

# 2. 安装依赖
npm install --production  # 仅安装生产依赖

# 3. 创建环境变量文件
cp .env.example .env
nano .env  # 填写生产环境变量

# 4. 初始化数据库
node scripts/initdb.js

# 5. 插入测试数据（可选）
node scripts/seed.js

# 6. 使用PM2启动应用
pm2 start app.js --name h5-quiz-api
pm2 save  # 保存进程列表（开机自启）
pm2 startup  # 生成开机自启脚本
# 执行PM2提示的sudo命令

# 7. 查看应用状态
pm2 status
pm2 logs h5-quiz-api  # 查看日志
```

#### **环境变量配置（.env）**

```bash

# CDN域名（用于拼接图片URL）

```

### 3.3 配置Nginx反向代理

```bash
# 1. 创建Nginx配置文件
sudo nano /etc/nginx/sites-available/h5-quiz
```

**配置文件内容**：
```nginx
# 前端静态资源（如使用Nginx托管）
server {
    listen 80;
    server_name cdn.xxx.com;  # 替换为你的域名

    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name cdn.xxx.com;

    # SSL证书配置
    ssl_certificate /etc/nginx/ssl/cdn.xxx.com.pem;
    ssl_certificate_key /etc/nginx/ssl/cdn.xxx.com.key;

    # 静态资源目录
    root /var/www/h5-quiz;
    index index.html;

    # 缓存策略
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2)$ {
        expires 365d;
        add_header Cache-Control "public, immutable";
    }

    # SPA路由支持（如需要）
    location / {
        try_files $uri $uri/ /index.html;
    }
}

# 后端API反向代理
server {
    listen 80;
    server_name api.xxx.com;  # 替换为你的API域名

    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.xxx.com;

    # SSL证书配置
    ssl_certificate /etc/nginx/ssl/api.xxx.com.pem;
    ssl_certificate_key /etc/nginx/ssl/api.xxx.com.key;

    # 反向代理到Node.js应用
    location / {
        proxy_pass http://localhost:3000;  # Node.js监听端口
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_cache_bypass $http_upgrade;
    }

    # 健康检查端点（可选）
    location /health {
        access_log off;
        return 200 "healthy\n";
    }
}
```

```bash
# 2. 启用配置
sudo ln -s /etc/nginx/sites-available/h5-quiz /etc/nginx/sites-enabled/
sudo nginx -t  # 测试配置语法
sudo systemctl restart nginx

# 3. 配置SSL证书（使用Let's Encrypt免费证书）
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d cdn.xxx.com -d api.xxx.com
# 按提示操作，证书会自动续期
```

## 6. 备份与恢复

### 6.1 数据库备份

```bash
# 1. 每日自动备份（使用crontab）
crontab -e

# 添加以下行（每天凌晨2点备份）
0 2 * * * /usr/bin/mysqldump -u root -p'your_password' h5_quiz > /backups/h5_quiz_$(date +\%Y\%m\%d).sql

# 2. 备份文件压缩（节省空间）
0 2 * * * /usr/bin/mysqldump -u root -p'your_password' h5_quiz | gzip > /backups/h5_quiz_$(date +\%Y\%m\%d).sql.gz

# 3. 删除30天前的备份
0 3 * * * find /backups -name "*.sql.gz" -mtime +30 -delete
```

## 8. 应急预案

### 8.1 服务器宕机

**症状**：网站无法访问，Ping不通服务器IP

**处理步骤**：
1. 登录云控制台，查看服务器状态
2. 如服务器已停止，尝试重启
3. 如无法重启，使用快照恢复系统
4. 通知用户（通过微信公众号推文）

**预防措**：
- 使用多台服务器（负载均衡）
- 定期创建系统快照（每天一次）
- 配置监控告警（服务器离线时通知）

### 8.2 数据库崩溃

**症状**：API返回500错误，日志显示数据库连接失败

**处理步骤**：
1. 尝试重启数据库服务
   ```bash
   sudo systemctl restart mysql  # 自建MySQL
   ```
2. 如无法修复，从备份恢复数据库
   ```bash
   gunzip < /backups/h5_quiz_最新备份.sql.gz | mysql -u root -p h5_quiz
   ```
3. 切换到备用数据库（如已配置主从复制）

**预防措**：
- 使用云数据库RDS（自动备份+故障转移）
- 配置主从复制（主库崩溃时切换到从库）
- 定期测试备份文件的恢复流程

### 8.3 高并发导致服务不可用

**症状**：网站响应极慢，API超时

**处理步骤**：
1. 查看服务器资源占用
   ```bash
   top  # 查看CPU/内存占用
   df -h  # 查看磁盘空间
   ```
2. 临时扩容（云服务器支持在线升级配置）
3. 启用限流策略（Nginx limit_req模块）
   ```nginx
   http {
       limit_req_zone $binary_remote_addr zone=one:10m rate=10r/s;
       server {
           location / {
               limit_req zone=one burst=20 nodelay;
               proxy_pass http://localhost:3000;
           }
       }
   }
   ```
4. 启动更多Node.js实例（负载均衡）
   ```bash
   pm2 scale h5-quiz-api +2  # 增加2个实例
   ```

**预防措**：
- 使用云服务器的自动扩容功能
- 配置CDN缓存，减少后端压力
- 使用Redis缓存热门数据

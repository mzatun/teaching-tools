# 青少年编程天赋免费测评H5工具 - UI设计稿

## 1. 设计目标

基于**科宝AI编程天赋测评**的设计理念，打造一款**趣味、友好、专业**的H5测评工具UI，确保6-15岁青少年能独立操作，同时吸引家长分享传播。

---

## 2. 设计规范

### 2.1 色彩体系

**主色调**：
- 品牌蓝：`#4A90D9` （科技感、信任感）
- 活力橙：`#FF6B35` （活力、创造力）
- 清新绿：`#7ED321` （成长、希望）

**辅助色**：
- 背景灰：`#F5F5F5`
- 文字深：`#333333`
- 文字浅：`#999999`
- 成功绿：`#52C41A`
- 警告橙：`#FAAD14`

**渐变效果**：
```
主渐变：linear-gradient(135deg, #4A90D9 0%, #7B68EE 100%)
按钮渐变：linear-gradient(135deg, #FF6B35 0%, #FF8C42 100%)
```

### 2.2 字体规范

| 用途 | 字体 | 字号 | 字重 |
|------|------|------|------|
| 主标题 | 思源黑体 | 24px | Bold |
| 副标题 | 思源黑体 | 18px | Semi-Bold |
| 正文 | 思源黑体 | 16px | Regular |
| 辅助文字 | 思源黑体 | 14px | Regular |
| 小字说明 | 思源黑体 | 12px | Light |

**字体文件**：
- 中文字体：思源黑体（Source Han Sans）
- 英文字体：Roboto
- 备用字体：PingFang SC, Microsoft YaHei, sans-serif

### 2.3 间距规范

| 元素 | 间距值 |
|------|----------|
| 页面边距 | 32px |
| 卡片圆角 | 16px |
| 按钮圆角 | 24px |
| 元素间距 | 16px / 24px |
| 段落间距 | 12px |

### 2.4 图标规范

- 图标库：iconfont（阿里巴巴矢量图标库）
- 图标尺寸：48×48px（标准）, 32×32px（小）, 64×64px（大）
- 图标风格：线性图标（2px描边）

## 4. 组件设计

### 4.1 通用组件库

#### **按钮（Button）**
```vue
<template>
  <button :class="['btn', `btn-${type}`, { 'btn-disabled': disabled }]">
    <slot></slot>
  </button>
</template>

<script>
export default {
  props: {
    type: {
      type: String,
      default: 'primary', // primary / secondary / outline
    },
    disabled: {
      type: Boolean,
      default: false
    }
  }
}
</script>

<style>
.btn {
  padding: 16px 48px;
  border-radius: 24px;
  font-size: 16px;
  border: none;
  cursor: pointer;
}

.btn-primary {
  background: linear-gradient(135deg, #FF6B35 0%, #FF8C42 100%);
  color: white;
  box-shadow: 0 4px 12px rgba(255, 107, 53, 0.4);
}

.btn-secondary {
  background: white;
  color: #4A90D9;
  border: 2px solid #4A90D9;
}

.btn-outline {
  background: transparent;
  color: #4A90D9;
  border: 2px solid #4A90D9;
}

.btn-disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
</style>
```

#### **卡片（Card）**
```vue
<template>
  <div :class="['card', { 'card-selected': selected }]">
    <slot></slot>
  </div>
</template>

<script>
export default {
  props: {
    selected: {
      type: Boolean,
      default: false
    }
  }
}
</script>

<style>
.card {
  background: white;
  border-radius: 16px;
  padding: 24px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  transition: all 0.3s;
}

.card-selected {
  border: 2px solid #4A90D9;
  background: #F0F5FF;
}
</style>
```

#### **进度条（ProgressBar）**
```vue
<template>
  <div class="progress-bar">
    <div class="progress-fill" :style="{ width: `${percent}%` }"></div>
    <span class="progress-text">{{ current }} / {{ total }}</span>
  </div>
</template>

<script>
export default {
  props: {
    current: Number,
    total: Number
  },
  computed: {
    percent() {
      return Math.round((this.current / this.total) * 100);
    }
  }
}
</script>

<style>
.progress-bar {
  position: relative;
  width: 100%;
  height: 12px;
  background: #E8E8E8;
  border-radius: 6px;
  overflow: hidden;
}

.progress-fill {
  height: 100%;
  background: linear-gradient(90deg, #4A90D9 0%, #7B68EE 100%);
  transition: width 0.3s;
}

.progress-text {
  position: absolute;
  right: 0;
  top: -24px;
  font-size: 14px;
  color: #999;
}
</style>
```

## 5. 动效设计

### 5.1 页面转场动画

```css
/* 页面进入动画 */
.page-enter {
  animation: slideInRight 0.3s ease-out;
}

@keyframes slideInRight {
  from {
    transform: translateX(100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

/* 页面退出动画 */
.page-leave {
  animation: slideOutLeft 0.3s ease-out;
}

@keyframes slideOutLeft {
  from {
    transform: translateX(0);
    opacity: 1;
  }
  to {
    transform: translateX(-100%);
    opacity: 0;
  }
}
```

### 5.2 按钮脉冲动画

```css
.btn-primary {
  animation: pulse 2s infinite;
}

@keyframes pulse {
  0% {
    box-shadow: 0 0 0 0 rgba(255, 107, 53, 0.4);
  }
  70% {
    box-shadow: 0 0 0 10px rgba(255, 107, 53, 0);
  }
  100% {
    box-shadow: 0 0 0 0 rgba(255, 107, 53, 0);
  }
}
```

### 5.3 雷达图绘制动画

```javascript
// ECharts雷达图动画配置
const option = {
  animationDuration: 1500, // 1.5秒动画
  animationEasing: 'cubicOut',
  series: [{
    type: 'radar',
    animationDelay: function(idx) {
      return idx * 200; // 每个维度延迟200ms
    }
  }]
}
```

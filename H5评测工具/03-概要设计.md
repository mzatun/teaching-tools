# 青少年编程天赋免费测评H5工具 - 概要设计

### 2.2 技术栈选型

| 层级 | 技术选型 | 选型理由 |
|------|----------|----------|
| **前端框架** | Vue.js 3.x（CDN引入） | 轻量、易上手、生态完善 |
| **UI组件** | Vant Weapp（移动端组件库） | 专为微信H5设计，体验优秀 |
| **绘图库** | ECharts（雷达图） | 配置简单，兼容性好 |
| **后端框架** | Node.js + Express | 前后端分离，开发效率高 |
| **数据库** | MySQL 8.0 | 成熟稳定，支持事务 |
| **缓存** | Redis | 提升读取性能（题目缓存） |
| **部署** | Nginx + PM2 | 反向代理 + 进程管理 |
| **云服务** | 阿里云/腾讯云 | 国内访问快，备案方便 |

### 3.2 核心模块详细设计

#### **M1：用户模块**

**功能列表**：
- `wxLogin()` - 微信授权登录，获取openid
- `selectGrade(grade)` - 选择年级（1-3/4-6/初中）
- `acceptPrivacy()` - 接受隐私协议

**数据结构**：
```javascript
// 用户对象
const user = {
  openid: 'oXYZ123...',      // 微信唯一标识
  nickname: '小明',           // 用户昵称
  grade: 2,                  // 年级段（1/2/3）
  acceptPrivacy: true,        // 是否接受协议
  createTime: 1714900000000  // 创建时间戳
}
```

#### **M2：测评模块**

**功能列表**：
- `getQuestions(grade)` - 根据年级获取题目（25题）
- `submitAnswer(qid, answer)` - 提交单题答案
- `prevQuestion()` / `nextQuestion()` - 题目导航
- `calculateScore()` - 计算五维得分

**题目结构**：
```javascript
// 题目对象
const question = {
  id: 1,
  grade: 2,                  // 适用年级段
  dimension: ['logic', 'creativity'], // 关联维度
  question: '小猫怎么走到小鱼？',  // 题目文本
  image: 'cat_fish.png',     // 配图（可选）
  options: ['A', 'B', 'C', 'D'], // 选项
  scores: {                  // 各选项得分
    A: { logic: 4, creativity: 2 },
    B: { logic: 2, creativity: 4 },
    C: { logic: 3, creativity: 3 },
    D: { logic: 1, creativity: 1 }
  }
}
```

#### **M3：结果模块**

**功能列表**：
- `calcDimensionScores(answers)` - 计算五维得分
- `generateRadarChart(scores)` - 生成雷达图（ECharts）
- `generateReport(scores)` - 生成文字报告
- `matchCourse(scores)` - 匹配推荐课程

**评分算法**：
```javascript
// 五维得分计算（归一化为百分制）
function calcDimensionScores(answers) {
  const dimensions = {
    logic: [],        // 逻辑思维
    creativity: [],   // 创意实现
    concept: [],      // 概念理解
    focus: [],        // 专注毅力
    collaboration: [] // 协作沟通
  };
  
  // 遍历答案，累加各维度得分
  answers.forEach(answer => {
    const question = getQuestionById(answer.qid);
    const scores = question.scores[answer.option];
    Object.keys(scores).forEach(dim => {
      dimensions[dim].push(scores[dim]);
    });
  });
  
  // 计算平均分并归一化（0-4分 → 0-100分）
  const result = {};
  Object.keys(dimensions).forEach(dim => {
    const avg = dimensions[dim].reduce((a, b) => a + b, 0) / 25;
    result[dim] = Math.round(avg * 25); // 0-4 → 0-100
  });
  
  return result;
}
```

#### **M4：分享模块**

**功能列表**：
- `generatePoster(radarImage, qrcode)` - 合成分享海报
- `configWxShare(title, desc, link)` - 配置微信分享
- `trackShare(userId, channel)` - 统计分享数据

**海报生成流程**：
```
1. 创建Canvas（750x1334）
2. 绘制背景图
3. 绘制雷达图（从ECharts导出图片）
4. 绘制二维码（客服微信/小程序码）
5. 绘制文案（"我的编程天赋测评结果"）
6. 导出为图片（PNG格式）
```

## 4. 数据流程设计

### 4.1 主流程图

```

    ↓

    ↓
```

## 5. 数据库设计（概要）

### 5.1 ER图（核心实体）

```
┌──────────┐       ┌──────────┐       ┌──────────┐
│  用户表   │       │  题目表   │       │  结果表   │
│ (User)   │       │(Question)│       │(Result)  │
└──────────┘       └──────────┘       └──────────┘
      │                  │                  │
      │ 1:N             │ 1:N             │ N:1
      ├──────────────────┼──────────────────┤
      │                  │                  │
      ↓                  ↓                  ↓
  openid            question_id        result_id
  nickname          grade              user_id (FK)
  grade             dimension          scores (JSON)
  create_time       question           report_url
                     ...               create_time
```

### 5.2 核心表结构（概要）

**用户表（users）**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| openid | VARCHAR(64) PK | 微信唯一标识 |
| nickname | VARCHAR(50) | 用户昵称 |
| grade | INT | 年级段（1/2/3） |
| create_time | BIGINT | 创建时间戳 |

**题目表（questions）**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT PK | 题目ID |
| grade | INT | 适用年级段 |
| dimension | VARCHAR(100) | 关联维度（逗号分隔） |
| question | TEXT | 题目内容 |
| options | JSON | 选项（A/B/C/D） |
| scores | JSON | 各选项得分 |

**结果表（results）**：
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT PK | 结果ID |
| user_id | VARCHAR(64) FK | 用户openid |
| scores | JSON | 五维得分 |
| report_url | VARCHAR(200) | 报告URL |
| create_time | BIGINT | 创建时间戳 |

## 7. 安全设计

### 7.1 数据安全

| 风险 | 应对措施 |
|------|----------|
| 用户数据泄露 | AES-256加密 + HTTPS传输 |
| SQL注入 | 使用参数化查询（PreparedStatement） |
| XSS攻击 | 前端输入过滤 + CSP策略 |
| CSRF攻击 | 使用JWT Token验证 |

### 7.2 防作弊机制

| 策略 | 实现方式 |
|------|----------|
| 限制测评次数 | 同一openid 7天内只能测一次 |
| 题目乱序 | 每次加载题目随机排序 |
| 选项乱序 | 每个选项显示位置随机 |
| 时间检测 | 答题时间<2分钟视为异常 |

## 8. 性能优化设计

### 8.1 前端优化

| 优化点 | 方案 |
|--------|------|
| 首屏加载慢 | 使用CDN加速静态资源 |
| 图片体积大 | 图片压缩（TinyPNG）+ WebP格式 |
| JS执行慢 | 代码分割（懒加载非首屏代码） |
| 渲染卡顿 | 使用requestAnimationFrame优化动画 |

### 8.2 后端优化

| 优化点 | 方案 |
|--------|------|
| 数据库查询慢 | 添加索引（openid, grade） |
| 并发压力大 | 使用Redis缓存热门题目 |
| 计算密集 | 评分算法放到后端异步处理 |
| 带宽成本高 | 启用Gzip压缩 + 图片CDN |

## 🚀 安装方法

### 前提条件
- 已安装 [WorkBuddy](https://www.codebuddy.cn)（v2.0+）
- 已配置技能管理（Skill Manage）

### 安装步骤

1. 下载本目录中对应的 `.zip` 技能包文件
2. 打开 WorkBuddy → **技能管理** → **安装技能**
3. 选择下载的 `.zip` 文件，确认安装
4. 安装完成后，在对话中直接使用对应技能关键字触发

> **示例**：安装 `jiaying-syllabus-generator.zip` 后，对话中输入「生成教学大纲」即可触发。

## 📋 各技能包详细说明

### 1. 嘉应学院教学大纲生成器
- **文件**：`jiaying-syllabus-generator.zip`
- **功能**：按嘉应学院教务处标准大纲格式，自动生成含课程信息、教学目标、教学内容、考核方式等 15 个标准章节的完整大纲
- **输出**：Word `.docx` 文件
- **触发词**：`生成教学大纲`、`嘉应学院大纲`、`syllabus`

### 2. ArcPy 课程笔记生成
- **文件**：`arcpy-course-notes.zip`
- **功能**：将 ArcPy 学习内容、课程要点、技术文档转化为多巴胺配色风格的专业 HTML 学习笔记
- **特色**：手绘手账风格，适合学生自学和教师备课
- **触发词**：`ArcPy笔记`、`生成学习笔记`、`course notes`

### 3. 毕业论文开题评审
- **文件**：`thesis-proposal-review.zip`
- **功能**：从现势性、可行性、技术路线、时间规划等维度评审毕设选题开题报告，输出专业建议
- **输出**：评审报告（Markdown / Word）
- **触发词**：`开题评审`、`毕设选题评审`、`thesis proposal review`

### 4. 简历评估助手
- **文件**：`resume-evaluator.zip`
- **功能**：解析学生简历，从教育背景、技能匹配、项目经验等维度生成评估报告，辅助就业指导
- **输出**：评估报告（HTML）
- **触发词**：`简历评估`、`简历分析`、`resume evaluator`

### 5. 教程逻辑化讲解
- **文件**：`tutorial-to-logic.zip`
- **功能**：将软件操作教程（步骤列表）转化为「数据对象 → 业务逻辑」的结构化 HTML 讲解页面，帮助深入理解操作背后的原理
- **特色**：支持联网扩展知识体系，引用教程配图
- **触发词**：`教程逻辑化`、`tutorial to logic`、`转化教程`

### 6. 科研全能助手
- **文件**：`research全能助手.zip`
- **功能**：覆盖科研全流程——论文复现、代码调试、数据分析、论文写作四个模块
- **适用**：本科生科研训练、毕业论文指导、教师科研备课
- **触发词**：`科研助手`、`research assistant`、`论文复现`

### 7. 知识图谱生成器
- **文件**：`knowledge-graph-skill.zip`
- **功能**：根据 JSON 格式的知识点结构定义文件，自动生成基于 D3.js 的交互式知识图谱网页
- **特色**：支持节点展开/折叠、缩放拖拽、层级高亮，适合课程知识体系可视化
- **输出**：交互式 HTML 知识图谱页面
- **触发词**：`知识图谱`、`knowledge graph`、`生成知识图谱`
- **示例**：含 Python 基础、ArcPy 游标与几何等多个示例图谱

### 8. 课程复习资料制作
- **文件**：`course-review-kit.zip`
- **功能**：将 PPT/PDF/Word 课件转化为两套复习资料：多巴胺手绘风 HTML 笔记 + 配套练习题
- **特色**：每个核心概念配 SVG/CSS 自循环动画，公式用 MathJax 渲染，不依赖图像生成工具
- **输出**：HTML 笔记 + Markdown 练习题
- **触发词**：`复习笔记`、`动画笔记`、`手绘笔记`、`刷题`、`课后练习`

### 9. 论文可视摘要生成
- **文件**：`paper-visual-abstract.zip`
- **功能**：将微信公众号 / arXiv / 期刊论文提炼为单文件 HTML「可视摘要单页」
- **特色**：八段式结构（概念预热→输入→流程→方法动画→瓶颈→结果→贡献→引用），双师型教学/产业双视角增强
- **输出**：单文件 HTML 可视摘要
- **触发词**：`论文导读`、`论文速读`、`可视摘要`、`一页看懂这篇论文`

### 10. 图表配图工具包
- **文件**：`diagram-figure-toolkit.zip`
- **功能**：统一处理论文配图、研究报告配图、软件文档配图、使用手册配图四类需求
- **特色**：自动判断需求类型，路由到最适合引擎——从零画图（arch-diagrammer / fireworks-tech-graph）或图片矢量化编辑（figedit）
- **输出**：SVG/PNG/draw.io 可编辑图
- **触发词**：`画图`、`生成图`、`架构图`、`流程图`、`论文配图`、`把这张图转成可编辑`

### 11. Word 模板报告生成
- **文件**：`docx-template-generator.zip`
- **功能**：根据 Word 模板（.docx）自动识别 `{{占位符}}`、填充内容并生成新文档
- **输出**：填充后的 Word 报告
- **触发词**：`生成Word报告`、`填充模板`、`按模板生成文档`、`docx template`、`word report`

### 12. ArcPy 工具箱全链路开发
- **文件**：`arcpy-analysis-toolbox-dev.zip`
- **功能**：从微信公众号/网络教程出发，经「教程网页化→综合工具箱开发→实验套件生成」三阶段，产出完整 ArcGIS Pro 脚本工具箱 + 实验教程
- **特色**：批量将 GIS 教程推文转化为可交付的教学三件套
- **输出**：.pyt 工具箱 + HTML 教程 + 5 文件实验包
- **触发词**：`从推文制作工具箱`、`arcpy工具箱开发`、`制作实验教程`、`GIS教程转脚本工具`

### 13. ArcGIS Pro 脚本插件生成
- **文件**：`arcpy-arcgis-pro-plugin-generator.zip`
- **功能**：根据 GIS 功能需求，生成基于 arcpy 的 ArcGIS Pro 地理脚本插件开发包
- **输出**：需求分析、业务逻辑、功能脚本、运行环境说明、完整教程
- **触发词**：`ArcGIS Pro 插件`、`arcpy 插件`、`地理脚本插件生成`

### 14. 三云平台方法论复现引擎
- **文件**：`cloud-platform-urban-center-replication.zip`
- **功能**：从论文/推文/教程中提取技术方案，适配到 GEE（JS）、PIE-Engine（JS）、OGE（Python）三平台
- **输出**：可运行脚本 + 三平台对比方案文档 + 配置测试教程
- **触发词**：`三平台复现`、`云平台脚本生成`、`论文方法迁移`、`GEE/PIE/OGE方案`

### 15. 计算机视觉模型方案
- **文件**：`cv-model-solution.zip`
- **功能**：学术前沿（CVPR/ICCV/ECCV/NeurIPS）+ 工程落地双轨，生成算法选型、数据集、训练、部署、模型评价完整方案
- **适用场景**：目标检测、实例分割、遥感解译、点云处理、无人机小目标检测等
- **触发词**：`模型训练方案`、`算法选型`、`部署方案`、`数据集推荐`、`model selection`

### 16. 智慧城市双师型专家
- **文件**：`smart-city-dual-expert.zip`
- **功能**：融合吴志强（系统之道）、郭仁忠（技术之器）、龙瀛（方法之术）三位学者思想，提供智慧城市/空间规划/城市科学领域的教学设计、科研方案、项目咨询、学生导学
- **触发词**：`智慧城市`、`CIM`、`GIS`、`城市科学`、`空间规划`、`数字孪生`、`城市治理`

### 17. 岗位 AI 驾驭诊断
- **文件**：`post-ai-diagnosis.zip`
- **功能**：基于岗位说明书三维度（判断系统、AI 工作流、结果责任），对企业具体岗位进行 AI 能力诊断
- **输出**：《岗位 AI 驾驭诊断报告》.md（3000-5000 字，可直接交付）
- **触发词**：`岗位AI诊断`、`AI工作流设计`、`人机合并方案`、`这个岗位怎么用AI`

### 18. 知识体系数据源整理
- **文件**：`kb-source-organizer.zip`
- **功能**：将任意领域知识拆解为 5 份 YAML（domain / dimensions / relation_types / knowledge_points / scenarios），强制本体论纪律（单根无环树、层级语义、重要性分化、维度用途、场景阶段内去重），校验后合并为 Consolidated JSON 知识数据源
- **适用**：知识体系结构化、知识图谱 / 可视化应用的数据准备
- **触发词**：`整理知识体系`、`知识图谱数据源`、`整理成yaml再转json`、`ontology`

### 19. 知识体系 HTML 应用构建
- **文件**：`kb-html-builder.zip`
- **功能**：把上游 `kb-source-organizer` 产出的 Consolidated JSON 注入母版模板，生成零 CDN、双击即开的单文件 HTML，含知识图谱 / 思维导图 / 矩阵 / 学习路线四视图与可交互侧栏
- **特色**：离线可用、无需任何运行时；与「知识图谱生成器」(#7) 构成「数据源 → 应用」升级版完整链路
- **输出**：单文件 HTML 知识体系可视化应用
- **触发词**：`生成知识体系HTML`、`知识图谱可视化`、`把json做成网页`、`build knowledge html`

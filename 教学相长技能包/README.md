## 🚀 安装方法

### 前提条件
- 已安装 [WorkBuddy](https://www.codebuddy.cn)（v2.0+）
- 已配置技能管理（Skill Manage）

### 安装步骤

1. 下载本目录中对应的 `.zip` 技能包文件
2. 打开 WorkBuddy → **技能管理** → **安装技能**
3. 选择下载的 `.zip` 文件，确认安装
4. 安装完成后，在对话中直接使用对应技能关键字触发

> **示例**：安装 `jiaying-syllabus-generator.zip` 后，对话中输入「生成教学大纲」即可触发。

## 📋 各技能包详细说明

### 1. 嘉应学院教学大纲生成器
- **文件**：`jiaying-syllabus-generator.zip`
- **功能**：按嘉应学院教务处标准大纲格式，自动生成含课程信息、教学目标、教学内容、考核方式等 15 个标准章节的完整大纲
- **输出**：Word `.docx` 文件
- **触发词**：`生成教学大纲`、`嘉应学院大纲`、`syllabus`

### 2. ArcPy 课程笔记生成
- **文件**：`arcpy-course-notes.zip`
- **功能**：将 ArcPy 学习内容、课程要点、技术文档转化为多巴胺配色风格的专业 HTML 学习笔记
- **特色**：手绘手账风格，适合学生自学和教师备课
- **触发词**：`ArcPy笔记`、`生成学习笔记`、`course notes`

### 3. 毕业论文开题评审
- **文件**：`thesis-proposal-review.zip`
- **功能**：从现势性、可行性、技术路线、时间规划等维度评审毕设选题开题报告，输出专业建议
- **输出**：评审报告（Markdown / Word）
- **触发词**：`开题评审`、`毕设选题评审`、`thesis proposal review`

### 4. 简历评估助手
- **文件**：`resume-evaluator.zip`
- **功能**：解析学生简历，从教育背景、技能匹配、项目经验等维度生成评估报告，辅助就业指导
- **输出**：评估报告（HTML）
- **触发词**：`简历评估`、`简历分析`、`resume evaluator`

### 5. 教程逻辑化讲解
- **文件**：`tutorial-to-logic.zip`
- **功能**：将软件操作教程（步骤列表）转化为「数据对象 → 业务逻辑」的结构化 HTML 讲解页面，帮助深入理解操作背后的原理
- **特色**：支持联网扩展知识体系，引用教程配图
- **触发词**：`教程逻辑化`、`tutorial to logic`、`转化教程`

### 6. 科研全能助手
- **文件**：`research全能助手.zip`
- **功能**：覆盖科研全流程——论文复现、代码调试、数据分析、论文写作四个模块
- **适用**：本科生科研训练、毕业论文指导、教师科研备课
- **触发词**：`科研助手`、`research assistant`、`论文复现`

## 📁 目录结构（解压后）

以 `jiaying-syllabus-generator` 为例：
```
jiaying-syllabus-generator/
├── SKILL.md              # 技能定义文件（核心）
├── README.md             # 使用说明
├── EXAMPLES.md           # 示例输出
├── IMPLEMENTATION_GUIDE.md  # 实现细节
├── INSTALLATION.md       # 安装指南
├── QUICK_REFERENCE.md   # 快速参考
└── INDEX.md              # 索引
```

> 💡 **提示**：技能包的核心文件是 `SKILL.md`，其他文档为辅助说明，安装后 WorkBuddy 会自动读取 `SKILL.md`。

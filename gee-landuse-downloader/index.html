📋 操作指引

代码已复制到剪贴板，请按以下步骤操作：

  1. 打开 GEE Code Editor（需科学上网）
  2. 点击编辑器区域，粘贴刚才复制的代码（Ctrl+V / Cmd+V）
  3. 点击编辑器上方 Run 按钮运行脚本
  4. 切换到右侧面板 Tasks 选项卡
  5. 点击任务旁的 Run 按钮启动导出
  6. 导出完成后，文件保存在 Google Drive 对应文件夹中

⚠️ 需要有效的 Google 账号和 GEE 权限。

## 三、HTML工具功能说明

### 3.1 界面设计

采用**下拉列表 + 详情卡片**的交互模式（适配15个数据集的量级）：

```
左侧栏                              右侧地图
┌─────────────────────┐
│ 📦 选择数据集         │
│ ┌─────────────────┐ │         ┌──────────────────┐
│ │ [下拉列表 ▼]     │ │         │                  │
│ │  全球数据集       │ │         │    Leaflet 地图   │
│ │  · Dynamic World │ │         │                  │
│ │  · ESA WorldCover│ │         │                  │
│ │  · ...           │ │         │                  │
│ └─────────────────┘ │         │                  │
│ ┌─────────────────┐ │         └──────────────────┘
│ │ 📋 详情卡片      │ │
│ │ 名称 / 来源 / ...│ │
│ │ [论文链接] [GEE] │ │
│ └─────────────────┘ │
│                     │
│ 🗺️ 研究区域         │
│ [绘制][省级][国家]   │
│                     │
│ 📅 时间范围          │
│                     │
│ ⚙️ 输出设置         │
│                     │
│ 📝 GEE 代码预览     │
│ [复制] [GEE打开]    │
│                     │
│ [📤 生成导出任务]   │
└─────────────────────┘
```

### 3.2 核心功能

1. **数据集选择**：下拉列表按范围分组（全球/中国/美国/欧洲），选中后展开详情卡片
2. **论文链接**：每个数据集卡片内嵌官方文档、论文DOI、GEE文档等链接
3. **研究区域**：手动绘制矩形 / 省级行政区 / 国家级 / 全球
4. **时间范围**：根据所选数据集动态调整可用年份
5. **GEE代码生成**：实时生成完整可运行的JavaScript代码
6. **一键导出**：代码自动在GEE Code Editor中打开，支持批量逐年导出

### 3.3 支持的数据集数量

**共15个数据集**，覆盖：
- 10m级：Dynamic World, ESA WorldCover, FROM-GLC10
- 30m级：GLC_FCS30D, GlobeLand30, FROM-GLC30, GLAD LC, CLCD, 中科院, AGLC, USGS NLCD
- 100m级：CORINE, CGLS-LC100
- 300m+：ESA CCI, MODIS MCD12Q1

## 四、使用方法

### 4.1 基本流程

1. 双击 `index.html` 在浏览器中打开
2. 从下拉列表选择目标数据集
3. 查看详情卡片确认数据集信息，点击链接查看论文
4. 在地图上绘制研究区域（或选择省级/国家级）
5. 设置时间范围和输出参数
6. 点击"生成导出任务" → 自动在GEE Code Editor中打开代码
7. 在GEE Tasks面板点击Run启动导出

### 4.2 注意事项

1. 需要有效的 Google Earth Engine 账号
2. 全球范围数据导出耗时较长，建议限定研究区域
3. 不同数据集分类体系不同，跨数据集对比需注意编码转换
4. 部分数据集(AGLC、中科院等)在GEE上可能需要额外申请权限
5. MODIS(500m)适合大尺度分析，不适合精细研究
6. Dynamic World近实时数据有延迟(通常数天)

### 4.3 数据集选择建议

| 研究需求 | 推荐数据集 |
|----------|-----------|
| 全球长时序(30年+) | GLC_FCS30D, ESA CCI |
| 高分辨率(10m) | Dynamic World, ESA WorldCover |
| 中国区域研究 | CLCD, 中科院土地利用 |
| 美国区域研究 | USGS NLCD |
| 欧洲区域研究 | CORINE |
| 近实时监测 | Dynamic World |
| 气候模拟 | ESA CCI, MODIS |
| 城市扩张 | Dynamic World, ESA WorldCover |
| 热带森林 | GLAD Land Cover |

## 五、技术架构

### 5.1 文件结构

```
gee-landuse-downloader/
├── index.html      # 单页面应用（HTML+CSS+JS，无需构建工具）
└── 教程方案.md     # 本文档
```

### 5.2 依赖

- Leaflet.js (CDN) — 交互式地图
- Google Earth Engine JavaScript API — 数据访问与导出

### 5.3 数据集配置

每个数据集定义包含：
- `filterType`: 决定GEE过滤逻辑
  - `dateRange`: 按日期范围过滤 (Dynamic World)
  - `yearEq`: 按年份属性过滤 (大多数数据集)
  - `fixed`: 固定期相，无年份过滤 (ESA WorldCover, USGS NLCD等)
- `classes`: 分类编码→名称+颜色映射
- `links`: 论文/文档链接数组

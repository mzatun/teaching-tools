## 一、环境准备（重要）

### 1.1 浏览器要求

推荐使用 **Chrome / Edge / Firefox** 最新版，直接双击 `index.html` 打开即可，无需安装任何软件。

### 1.2 Google Earth Engine 账号

本工具**不直接连接 GEE**，而是生成代码后由用户粘贴至 GEE Code Editor 运行。因此你需要：

1. **拥有 Google 账号**（Gmail）
2. **申请 GEE 权限**：访问 https://signup.earthengine.google.com/ 提交申请，通常 1-3 天内审批通过
3. **登录 Google 账号**：在浏览器中登录你的 Google 账号

### 1.3 科学上网提示

> **GEE Code Editor (code.earthengine.google.com) 是 Google 服务，在中国大陆需要科学上网才能访问。**

| 场景 | 是否需要科学上网 |
|------|------------------|
| 打开本工具 (index.html) | 不需要 |
| 查看地图底图（天地图） | 不需要 |
| 复制代码后跳转 GEE | 需要 |
| 在 GEE Code Editor 中运行代码 | 需要 |
| 导出数据到 Google Drive | 需要 |

### 1.4 天地图 API Key

本工具使用天地图作为底图（WGS84 坐标，无偏移）。如需更换 Key：
- 申请地址：https://console.tianditu.gov.cn/
- 免费注册即可获取 Key

## 三、操作步骤

### 步骤 1：选择数据集

1. 点击左侧 **📦 选择数据集** 面板
2. 从下拉列表中选择目标数据集（按全球/中国/美国/欧洲分组）
3. 下方自动展开**详情卡片**，显示：
   - 数据集全称、来源机构、分辨率、时间跨度
   - GEE Collection ID
   - 数据集描述
   - 论文链接、官方文档链接
4. 右侧地图自动显示**分类图例**

**数据集分类说明**：

| 标记 | 含义 |
|------|------|
| 🟢 无标记 | 公开可用，直接生成代码即可使用 |
| ⚠️ 需申请 | 需先在 GEE Code Editor 中搜索该数据集并申请访问权限 |

**数据集选择建议**：

| 研究需求 | 推荐数据集 |
|----------|-----------|
| 全球高分辨率 (10m) | Dynamic World、ESA WorldCover |
| 全球 30m | GLAD Land Cover |
| 中国区域 | CLCD（需申请）、中科院土地利用（需申请） |
| 美国区域 | USGS NLCD |
| 全球长时序 (30年+) | GLC_FCS30D（需申请）、MODIS |
| 近实时监测 | Dynamic World |
| 气候模拟 | MODIS、CGLS-LC100 |

### 步骤 2：设置研究区域

点击 **🗺️ 研究区域** 面板，支持 6 种模式：

#### 2.1 手动绘制（默认）
- 在地图上**按住鼠标左键拖拽**绘制矩形
- 松开鼠标完成选定

#### 2.2 省级
- 点击 **省级** 按钮
- 从下拉框选择省份
- 地图自动缩放到该省并显示蓝色边界轮廓

#### 2.3 市级
- 点击 **市级** 按钮
- 先选择省份 → 再选择城市
- 地图自动缩放到该市并显示边界

#### 2.4 县区级
- 点击 **县区级** 按钮
- 选择 省份 → 城市 → 县区（三级联动）
- 地图自动缩放到该县区并显示边界

#### 2.5 国家级
- 点击 **国家级** 按钮
- 从下拉框选择国家（支持 10 个常用国家）

#### 2.6 全球
- 点击 **全球** 按钮
- 导出范围为全球（-180°～180°, -60°～85°）

> **提示**：行政边界数据来自阿里 DataV，选择省/市/县区时会自动从网络加载边界 GeoJSON。

### 步骤 3：设置时间范围

- **起始年份** / **结束年份**：根据所选数据集自动调整可选范围
- **逐年导出**：勾选后，每个年份单独生成一个导出任务

### 步骤 4：配置输出参数

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 输出分辨率（米） | 导出影像的像元大小 | 30m（与大多数数据集匹配） |
| 坐标系 | 输出投影 | WGS84 (EPSG:4326) |
| Google Drive 文件夹名 | 导出文件存放的文件夹 | GEE_LandUse |

### 步骤 5：配置 DEM 地形数据（可选）

在 **⚙️ 输出设置** 面板底部，勾选 **"同时下载 DEM 地形数据"** 可同时导出该区域的高程数据。

| 选项 | GEE ID | 分辨率 | 说明 |
|------|--------|--------|------|
| SRTM 30m（推荐） | USGS/SRTMGL1_003 | 30m | 全球80%陆地覆盖 |
| SRTM 90m | USGS/SRTMGL1_003 | 90m | 重采样，适合大尺度分析 |

DEM 数据会作为独立的导出任务出现在 GEE Tasks 面板中。

### 步骤 6：地图底图切换

地图右上角有图层切换控件，支持三种底图：

| 底图 | 说明 |
|------|------|
| **矢量图** | 默认，天地图矢量底图 + 中文地名标注 |
| **影像图** | 卫星影像 + 标注，适合查看实际地表 |
| **地形图** | 地形晕渲 + 标注，适合查看地形起伏 |

### 步骤 7：复制代码并执行

1. 点击 **📋 复制代码** 按钮，代码已复制到剪贴板
2. 点击 **📤 复制代码并查看操作指引** 按钮
3. 在弹出的指引面板中查看操作步骤
4. 打开 [GEE Code Editor](https://code.earthengine.google.com/)（需科学上网）
5. 在编辑器中粘贴代码（Ctrl+V / Cmd+V）
6. 点击 **Run** 按钮运行脚本
7. 切换到右侧面板 **Tasks** 选项卡
8. 点击任务旁的 **Run** 按钮启动导出
9. 导出完成后，文件保存在 Google Drive 对应文件夹中

## 四、GEE Code Editor 中的注意事项

### 4.1 逐年导出

如果勾选了"逐年导出"，Tasks 面板会显示多个任务（每个年份一个）。可以：
- 逐个点击 Run 启动
- 或点击 Tasks 面板顶部的 **Run all** 批量启动

### 4.2 导出状态

| 状态 | 说明 |
|------|------|
| Ready | 待运行 |
| Running | 正在导出（可能需要几分钟到几小时） |
| Completed | 导出完成，文件已在 Google Drive |
| Failed | 导出失败（通常是区域太大或配额不足） |

### 4.3 下载数据

导出完成后：
1. 访问 https://drive.google.com
2. 进入对应文件夹（默认 GEE_LandUse）
3. 下载 .tif 格式的影像文件

## 五、常见问题

### Q1：复制代码后在 GEE 中运行报错 "Image asset not found"？

**原因**：部分数据集（标记为 ⚠️ 需申请）需要先在 GEE 中申请访问权限。

**解决**：
1. 在 [GEE Code Editor](https://code.earthengine.google.com/) 的搜索框中搜索该数据集名称
2. 点击搜索结果进入数据集页面
3. 点击 **Request Access** 申请访问权限
4. 等待审批通过后重新运行代码

### Q2：导出任务失败，提示 "User memory limit exceeded"？

**原因**：研究区域太大，超出 GEE 计算配额。

**解决**：
1. 缩小研究区域（选择更小的行政区划或绘制更小的矩形）
2. 降低输出分辨率（如从 10m 改为 30m）
3. 缩短时间范围

### Q3：选择省/市/县区时下拉列表为空？

**原因**：边界数据加载失败（网络问题）。

**解决**：
1. 检查网络连接
2. 尝试重新选择省份触发加载
3. 如果持续失败，可使用"手动绘制"模式代替

### Q4：地图底图不显示？

**原因**：天地图服务暂时不可用。

**解决**：
1. 刷新页面重试
2. 检查天地图 API Key 是否有效

### Q5：不同数据集的分类体系不同，如何对比？

各数据集的分类编码和类别数量不同，建议：
1. 参考详情卡片中的分类图例
2. 导出后在 GEE 中进行重分类
3. 查看各数据集的论文了解分类定义

### Q6：DEM 数据导出失败？

**原因**：SRTM DEM 覆盖范围为南纬60°至北纬60°，超出范围无数据。

**解决**：
1. 确认研究区域在 SRTM 覆盖范围内
2. 检查 GEE 中是否能正常加载该数据集

## 七、技术说明

- **单文件应用**：仅 `index.html` 一个文件，无需构建工具，双击即可运行
- **底图服务**：天地图 WMTS 瓦片（WGS84 坐标，无偏移）
- **边界数据**：阿里 DataV 地理数据 API
- **代码生成**：所有配置实时转换为 GEE JavaScript 代码
- **DEM 数据**：SRTM 30m（USGS/SRTMGL1_003），通过 `ee.Image()` 直接加载
